# Boss直聘候选人AI评分助手

一个帮你「从 Boss 直聘招人」的电脑小助手：它会代替你在 Chrome 浏览器里翻候选人、把每位候选人的简历交给 AI 打分、最后把所有结果整理成一张 Excel 表格发给你。

**适合人群**：负责招聘、但不想一个个点开简历看的人。不需要会写代码，跟着下面的步骤操作就行。

> 说明：软件只是自动帮你操作浏览器和整理信息。打分是 AI 的**参考意见**，最终要不要这个人，请以你的专业判断为准。

---

## 它能帮你做什么

打开 Boss 直聘招聘端，选择你正在看的页面，软件会自动完成三件事：

1. **提取候选人** —— 逐个打开候选人简历，把基础信息（姓名、年龄、学历、工作年限等）和简历内容读出来
2. **AI 评分** —— 按照岗位要求，给每位候选人打一个 0-100 的匹配分，并写出评分理由
3. **导出 Excel** —— 把评分结果整理成一张带格式的表格（也可以顺便发到你的邮箱）

还可以选择**自动打招呼**：评分完成后，自动给分数达到要求的候选人发送沟通消息，省去手动一个个点（**目前只有「推荐牛人页」支持自动打招呼**）。

支持从 **三个页面** 提取候选人：

| 提取来源 | 在哪看 | 适合什么场景 |
|---|---|---|
| **推荐牛人页** | BOSS 直聘里的「推荐牛人」页面 | 系统根据你的招聘要求推荐的候选人 |
| **搜索页** | BOSS 直聘里的「搜索」页面 | 你自己用关键词搜出来的候选人 |
| **沟通页** | BOSS 直聘的「沟通」页面 | 已经和你聊过天的候选人 |

## 开始前需要准备什么

- 一台 **Windows 电脑**
- **Chrome 浏览器**
- 一个 **Boss 直聘招聘端账号**
- 一个 **AI 服务地址**（软件用它来评分，第一次使用时配置一次就行）

### ⚠️ 重要：运行中的注意事项

软件是通过 Chrome 的调试接口，在浏览器内部自动操作页面的（自动点开简历 → 直接读取简历文本，读不到会模拟「选中复制」提取全文，实在不行再截图识别 → AI 打分）。运行期间**不需要你碰电脑**，但有几个要点需要注意：

**1. 点「开始提取分析」时，软件会自动把 Chrome 切成「边用边跑」模式**

「边用边跑」模式会用特殊参数启动 Chrome，让 Chrome 窗口被遮挡/最小化时也照常渲染，这样就能**边用电脑边跑**了。点开始后软件会自动检查：

- Chrome 已经在「边用边跑」模式 → 直接开始
- Chrome 在普通模式运行 → 弹窗询问是否重启 Chrome（**会关闭当前标签页**），确认后自动重启；**重启后自己重新打开 Boss 直聘页面**，**再点一次「开始提取分析」**即可
- Chrome 没在运行 → 自动用「边用边跑」模式启动，打开 Boss 直聘页面后，再点一次「开始提取分析」

**2. 滚动加载候选人时，先别把 Chrome 最小化**

软件第一步要在网页里往下滚动加载候选人列表。这一阶段**不要把 Chrome 最小化、也不要盖住它**。等列表加载完、进度条进入逐个「读取简历」阶段（直接读文本或截图识别）后，就可以放心用电脑了——**把 Chrome 最小化去干别的也行**（前提是 Boss 直聘保持在 Chrome 最前面的标签页，别切走，见下面「开两个 Chrome」）。截图时软件**只在必要的时候**（Boss 页被切到后台）才把它拉回最前——如果 Boss 页一直正常显示着，软件不会打扰你，也不会抢你正在用的窗口。

> 简单说：点开始后先别动 Chrome；看到进度条开始「读取简历」后，就可以最小化 Chrome 去干别的了。

**想边跑边用电脑上别的网页？开两个 Chrome 就行**

同一个 Chrome 里如果新建标签页开别的网页，Boss 直聘就被挤到后台标签页去了，截图容易出问题。正确做法是开**两个 Chrome**：

- 一个 Chrome 专门跑 Boss 直聘（让 Boss 直聘一直保持在这个 Chrome **最前面的标签页**，别切走）
- 另一个 Chrome 用来开你其他要用的网页

这样截图就不会出问题。注意：第二个 Chrome 只用来开**别的网页**，不要在它里面开 Boss 直聘。

**3. 运行时不要开第二个 Boss 直聘窗口**

一次只用一个 Chrome 窗口跑 Boss 直聘。运行期间如果你需要用 Boss 直聘，用**手机 APP** 操作即可，别在电脑上再开第二个 Boss 窗口或标签页，避免干扰软件正在操作的页面。

**4. 非 VIP 账号每天查看候选人数量有限制**

Boss 直聘非 VIP 账号每天能查看的候选人数量有限制（尤其是推荐牛人页），用完后当天可能就无法继续了。**推荐优先用「搜索页」提取**，搜索页相对更不容易触发每日查看限制。

**5. 最省心：用一台闲置的电脑跑**

- **中午吃饭时**：打开软件开始跑，回来时通常已经有结果了
- **晚上下班前**：打开软件开始跑，第二天早上看结果

运行期间软件会**自动阻止电脑息屏/休眠**，不会因为电脑自动锁屏而让任务中途暂停——你可以安心离开，回来时结果已经在等你了（如果公司有强制锁屏策略，那种锁屏是压不住的，需要联系 IT）。

**6. 速度参考**

速度主要看简历是怎么读的：

- **直接读取简历文字**（简历文本能读出来时）——大约 **10 分钟能跑完 100 人左右**
- **截图识别**（简历是图片、只能截图后 AI 识字时）——大约 **30 分钟能跑完 100 人左右**

具体时间会因电脑性能和简历页数略有差异。

## 第一次使用，一步步来

### 第 1 步：给 Chrome 开一个「远程控制」小开关

软件需要像「遥控器」一样控制你的 Chrome 去浏览 Boss 直聘，所以要先在 Chrome 里开一个允许控制的开关。**这一步只做一次，以后不用再开。**

1. 打开 Chrome 浏览器，在地址栏输入下面的内容，按回车：
   ```
   chrome://inspect/#remote-debugging
   ```
2. 找到 **「Allow remote debugging for this browser instance」**，把前面的勾**打上**
3. 完全关闭 Chrome（包括托盘里的小图标），再重新打开，让设置生效

![Chrome 远程调试开关位置](docs/images/图1.png)

### 第 2 步：在 Chrome 里登录 Boss 直聘

用刚才的 Chrome 打开 Boss 直聘招聘端，登录你的招聘账号。

### 第 3 步：启动软件，确认连接正常

双击 `Boss直聘候选人AI评分助手.exe` 启动软件。看软件**最上方**的连接状态：

- 🟢 **绿色** = Chrome 连接正常，可以继续
- 🟡 **黄色** = 正在连接，稍等几秒
- 🔴 **红色** = 没连上，点旁边的「重试」，或确认第 1 步做完了

![软件主界面](docs/images/图2.png)

### 第 4 步：配置 AI（软件评分就靠它）

点软件里的 **「API 配置」**，展开后需要填三个信息：

1. **API 地址** —— 打开公司的 **AI API 系统**（全志单点登录 → AI API 系统 → 我的 API Key），选择 **Anthropic 格式**，把系统显示的 API URL 复制过来，格式类似：
   ```
   http://XXX.XXX.XXX.XX:XXXX/
   ```
2. **API Key** —— 在刚才那个页面复制你自己的 API Key，粘贴进来
3. **模型名称** —— 填 `deepseek-v4-flash_DeepSeek`（模型可以自由选择，这里只是建议用 DeepSeek Flash，系统里能用的其他模型也可以填）

![在 AI API 系统中复制 API 地址和 Key](docs/images/图3.png)

下面还有两个可选项：

- **邮件通知（可选）** —— 填你自己的完整邮箱（比如 `zhangsan@allwinnertech.com`），评分结果 Excel 会自动发到你自己的邮箱。发邮件还需要在下方填 **邮箱密码**（发件邮箱的登录密码；公司邮箱若开启了三方客户端安全密码，要填客户端安全密码而不是登录密码），不填则无法发送
- **输出目录** —— Excel 保存的位置，默认在「我的文档 → output」，也可以点「选择目录」自己定

都填好后，点 **「保存配置」**。「API 配置」标题旁边的状态会变成 **「✓ 已配置」**，就可以开始使用了。如果显示「未配置」，说明有项没填对，检查一下再保存。

![软件里的 API 配置面板（填写地址 / Key / 模型）](docs/images/图4.png)

### 第 5 步：添加你要招聘的岗位

软件打分时，需要知道「这个岗位看重什么」。每个岗位都要提前加进来。

1. 在软件里找到 **「目标岗位」**，点它，再点 **「+ 添加新岗位」**
2. **岗位名称**：可以直接复制 Boss 直聘上这个岗位的名字，也可以自己起名（建议带上城市和薪资方便区分），例如：
   ```
   AI大模型工程师 _ 深圳 30-50K
   ```
   （带 `/` 之类的符号也没关系，软件会自动处理）
3. **岗位描述**：⚠️ **注意，不要直接把 Boss 上的招聘 JD 复制进来。** 岗位描述要用 AI 生成，格式才能被软件正确识别。

**岗位描述怎么生成（三步）：**

1. 找到这个岗位的 JD
2. 打开任何一个聊天 AI（如 DeepSeek、Kimi、豆包等），把 JD 连同下面这段提示词一起发给它，让它把 JD 转成软件需要的格式：

   ```text
   请基于以上岗位 JD，完成以下两项分析任务。

   任务一：提取核心评估维度
   从 JD 中识别出 最核心的 3 个评估维度，并为每个维度分配权重，三项权重之和须为 100%。
   任务二：提取任职资格关键筛选项
   从 JD 中提取出所有 可量化的、客观的筛选条件，至少包括但不限于：学历、专业、工作经验年限、行业背景、专业技能/证书、其他强制性条件，不包括沟通能力、团队协作等软性素质。

   输出格式：
   核心评估维度及权重
   1. [评估维度名称]（[权重]%）：[具体要求]
   2. [评估维度名称]（[权重]%）：[具体要求]
   3. [评估维度名称]（[权重]%）：[具体要求]
   任职资格关键筛选项
   1. 学历要求：[具体要求]
   2. 经验要求：[具体要求]
   3. 行业/领域要求：[具体要求]
   4. 技能/证书要求：[具体要求]
   5. 其他硬性条件：[具体要求，如无则填“无”]

   所有提取内容不得臆造、不得遗漏。如 JD 中未明确某项，请标注“未明确”。
   ```

3. 把 AI 输出的结果，复制粘贴到软件的「岗位描述」输入框里，点 **「保存」**

这样岗位就加好了。以后在「目标岗位」里可以随时切换、编辑或删除岗位。岗位多的时候，点开「目标岗位」，列表上方有搜索框，输入关键词就能快速过滤，不用一个个翻找。

![添加新岗位弹窗](docs/images/图5.png)

### 第 6 步：设置提取数量并开始

1. 在 Chrome 里打开对应的 Boss 直聘页面（并设置好筛选条件，**不要刷新页面**）
2. 在软件里选 **「提取来源」**：推荐牛人页 / 搜索页 / 沟通页
3. 选好 **「目标岗位」**（推荐牛人页和搜索页需要）
4. **设置「提取数量」**：填一个数字（比如 `20`），就是提取前 20 位候选人；沟通页还可以勾选「提取全部」，把当前列表里的候选人都处理完
5. 点 **「▶ 开始提取分析」** —— 软件会自动把 Chrome 切成「边用边跑」模式（见「运行中的注意事项」）。如果 Chrome 被重启了，重新打开 Boss 直聘页面，**再点一次开始**即可

## 日常使用

### 三种提取来源怎么操作

都是先在 Chrome 打开对应页面、设好筛选条件（**不要刷新页面**），再到软件里选对应来源开始提取。各来源的特别说明：

- **推荐牛人页**：页面顶部的「推荐 / 精选 / 最新」三个导航都可以；单次最多能提取 **450 人**（Boss 网站限制，填更多也只提取这么多）
- **搜索页**：跑完**不会自动打招呼**（打招呼要畅聊卡，单独付费），评分结果都在 Excel 里，自己看着打招呼
- **沟通页**：支持「提取全部」，把当前列表里的候选人都处理完

### 运行过程中

软件分三步走：**① 提取候选人信息 → ② AI 评分 → ③ 导出 Excel**，每一步都有进度条。

- **跳过提取**：如果已经提取了一部分、不想等了，可以点「跳过提取候选人」，用已提取的数据直接开始评分
- **取消**：点「取消」停止本次任务

### 完成后

全部完成后会显示成功页面，你可以：

- **📂 打开输出目录** —— 找到导出的 Excel 表格（`candidates.xlsx`）
- **批量打招呼** —— 如果配置了邮件通知，Excel 会同时发到你邮箱；然后可以给分数达标的候选人**自动打招呼**，选一个分数门槛，点「开始打招呼」（只有「推荐牛人页」支持）
- **🔄 重新开始** —— 再跑一批

![完成界面与批量打招呼](docs/images/图6.png)

### 打分与打招呼的分数门槛

AI 会按岗位描述里的 **3 个核心评估维度**（带权重）给候选人打分，再根据学历、经验、技能等**硬性条件**核减，最后得出 0-100 分。打分结果和打招呼的档位是配套的，一张表看懂：

| 档位 | 分数门槛 | 打分结果 |
|---|---|---|
| 五星 | 91 分以上 | 强烈推荐 |
| 四星及以上（默认） | 81 分以上 | 推荐 |
| 三星及以上 | 61 分以上 | 可考虑 |
| 二星及以上 | 31 分以上 | 可考虑 |
| 全部候选人 | 不限制 | 全部 |

> 打招呼就是按档位选「多少分以上的候选人」自动发消息，默认从「四星及以上」开始。

## 常见问题

### 1. 遇到任何问题，先试试重启

遇到任何问题（提取不到、评分失败、卡住、界面异常等），**请先关闭本软件和 Chrome 浏览器，然后重新启动再试**。八成以上问题重启一次就能解决。如果重启后仍然不行，再对照下面更具体的问题排查。

### 2. 觉得 AI 评分不准 / 评级理由匹配度差

- **检查「岗位描述」是否用三段式 prompt 处理过 JD**。岗位描述应该是在聊天 AI 里用 README「第 5 步」的提示词把 JD 转换出来的格式（核心评估维度+权重、任职资格筛选项），**不要直接粘贴原始招聘 JD**——原始 JD 格式杂乱，AI 提取的评估维度容易跑偏。
- **AI 生成的岗位描述可以根据实际情况自行调整**：比如某个维度的权重觉得不合适，就改百分比；想加硬性条件（如"必须是统招本科"）就补一条限制进去。
- 评分前记得选好「目标岗位」，确保该岗位的「岗位描述」已保存。

### 3. 软件左上角一直显示红色 / Chrome 连接不上

- 确认第 1 步的 Chrome「远程调试」开关开了，并且**重启过 Chrome**
- 确认你是用 Chrome（而不是 Edge 等其他浏览器）登录 Boss 直聘的
- 点软件里的「重试」按钮，或重启一下软件

### 4. 点了开始，但一个候选人都提取不到 / 数量不对

- 检查是不是在**滚动加载候选人**那一步把 Chrome 最小化了（或盖住了）——这一阶段 Chrome 必须正常显示着，候选人列表才加载得出来（见「运行中的注意事项」第 2 条）

### 5. AI 评分失败，或者一堆人得了 0 分

- 先确认「API 配置」里三项都填了，状态是 **「✓ 已配置」**
- API Key 失效或网络不通时，评分会失败，重新获取 Key 或检查内网连接
- 如果整批人都失败，看看软件日志里的报错提示，一般是 API 地址或 Key 填错了

### 6. 找不到我要的岗位 / 想改岗位描述

- 点「目标岗位」→「+ 添加新岗位」可以新增（添加方法见「第 5 步」）
- 想修改，在「目标岗位」列表里找到这个岗位，点旁边的 **「编辑」**
- 想删除，点 **「删除」**（删了不影响已经导出的 Excel）

### 7. 邮件收不到

- 确认「邮件通知」里填的是**完整邮箱**，例如 `zhangsan@allwinnertech.com`
- 确认「API 配置」里填了 **邮箱密码**。⚠️ **公司邮箱最常见的一个坑**：账号开启「三方客户端安全密码」后，原来的登录密码就不能再用来配软件了，必须去网页版邮箱「邮箱设置 → 账户与安全 → 账户安全 → 三方客户端登录安全管理」获取一次性展示的**客户端安全密码**，填它（不是登录密码）。没填会提示「未配置邮箱密码」
- 邮件是**评分完成导出后**才发送的。看完成页面：显示「邮件已发送至」才是真发出去了；显示「⚠ 邮件发送失败：…」时，先按提示里的"处理办法"自测：到网页版邮箱用同一个密码登录、发一封邮件试试。**网页版也登不上 = 密码不对**（可能记错、改过、或太久没登录被要求先改密），更新「API 配置 → 邮箱密码」后重新导出一遍；**网页版能发但软件还是报错**，多半就是这个邮箱账号开了「三方客户端安全密码」，要用客户端安全密码而不是登录密码
- 偶尔会进垃圾箱，去垃圾箱找找看

### 8. 打招呼失败 / 卡住

- 打招呼失败时，弹窗会直接显示**具体原因**（比如「未找到推荐牛人页」），照着提示处理即可，不会只显示一句笼统的报错
- **页面没开对**：确认「推荐牛人页」已经用 Chrome 打开着，软件是在你打开的那个页面里找人打招呼
- **人数多时要耐心等**：打招呼时间会随目标人数增长（80 人左右约 13 分钟），进度条正常往前走就说明没问题，别中途关闭
- **个别候选人没招呼成功**：某个人操作超时（30 秒）或页面上找不到，软件会跳过继续下一个，不影响整体，最后看统计结果就行

## 给开发者的话（技术概要）

- 技术栈：**Electron + Node.js**，通过 Chrome DevTools 协议（CDP）代理控制浏览器
- 主要模块：
  ```
  electron/main.mjs                         主进程：流程编排、IPC、CDP 管理
  electron/score-comment.mjs                评语→评分的程序化计算 + 学历硬性门槛兜底扣分（共享模块）
  electron/renderer/                        界面（index.html / renderer.js / style.css）
  scripts/cdp-proxy.mjs                     HTTP → WebSocket 代理，控制 Chrome（端口 3456）
  scripts/extract-recommend-candidates.mjs  推荐牛人页提取
  scripts/extract-search-candidates.mjs     搜索页提取
  scripts/extract-candidates-full.mjs       沟通页提取
  scripts/greet-candidates.mjs              批量打招呼
  scripts/export-candidates.mjs             Excel 导出 + 邮件
  config/scoring-prompt-*.txt               AI 评分提示词模板
  %AppData%/web-access/web-access/jd-descriptions/   岗位描述（存用户数据目录，重装/升级不丢）
  ```
- 常用命令：
  ```bash
  npm install        # 安装依赖
  npm start          # 开发模式运行
  node scripts/cdp-proxy.mjs   # 单独运行 CDP 代理（调试用）
  npm run pack       # 打包构建（icon → electron-builder → NSIS → release）
  ```
- 详细开发文档见 [CLAUDE.md](CLAUDE.md)

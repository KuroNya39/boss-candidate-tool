# 设计系统（UI 规范）

界面规范的单一来源：颜色、间距、字号、行高、圆角、阴影、焦点环、动效、z-index 一律取自 `electron/renderer/tokens.css` 顶部 `:root` 的「设计 token」。改 UI 只引用 token、不写死数值；改了 token 必须同步本文件对应表格。

样式拆成 **6 个 CSS 文件**，`index.html` 中 `<link>` 的排列顺序 = 拆分前的文件内顺序，**勿调换**（否则级联结果变化）。级联顺序的唯一权威是 `index.html` 的 `<link>` 顺序：

| 文件 | 内容（按文件内 `/* ===== 分节 ===== */` banner） |
|---|---|
| `tokens.css` | `:root` 全部 token（字体 / 字号 / 间距 / 色彩 / 圆角 / 阴影 / 焦点环 / 时长缓动 / z-index） |
| `base.css` | reset、滚动条策略、`button` 重置、键盘焦点环、`#app` 页面壳 |
| `topbar.css` | 页头标题与版本号、连接状态容器、Chrome 状态栏 |
| `config.css` | 首页配置区控件（岗位选择、字段、分段钮、下拉、开关、折叠卡、按钮体系等） |
| `run.css` | 执行进度步骤条、结果头 / 摘要 / 错误、批量打招呼 |
| `overlays.css` | 弹窗 / Toast / 完成页结果可视化 / 历史抽屉 / 全局关键帧 |

> 拆分只是按原顺序「分桶」，不是按功能语义归属——某选择器具体在哪，按各文件内分节 banner 检索，勿按「文件名 = 功能」倒推。

界面逻辑为 `renderer-*.js` 10 个小文件，按 `index.html` 中的 `<script src>` 顺序引入、共享全局作用域（DOM 引用只在 `renderer-dom.js` 顶部），顺序同样勿调。

## 0. 设计原则

改 UI 前先对照此纲，每条指向落点：

1. **工具优先**：面向 HR 长时间使用的效率工具——密度中等偏紧凑，常用操作一屏放下；鼠标为主、键盘可达。
2. **色彩是语义系统**：色板 = 中性灰阶 + 唯一 accent + 语义色阶（成功 / 警告 / 错误 / 信息）+ 档位色阶；颜色一律走 token，无语义挪用、无裸值。accent 是唯一品牌强调色，其余彩色只表达语义或档位。→ §1
3. **层级由尺寸主导**：越大越重要，辅以灰阶与少量加粗；颜色不作唯一层级信号。→ §3
4. **间距走 8 网格**：间距 / 尺寸取 4（半拍）/ 8 / 16 / 24 / 32 / 48 / 64，不取 12 / 20 / 28 等非网格值。→ §2
5. **留白即层级**：重要的东西周围要「空」；宁可空着也不硬塞。→ §2、§6
6. **邻近成组**：相关内容放一起自动成组，无关内容拉开间距——分组靠间距，不靠描边线框。→ §2、§6
7. **单列优先**：内容默认一列到底，确有空间与成对语义才多列。→ §6
8. **渐进披露**：核心内容开箱即用；次要内容收进折叠卡 / 二级页 / 弹窗。→ §6、§8
9. **状态模型完整**：可交互组件至少五态齐全——静置 / 悬停 / 按下 / 键盘聚焦 / 禁用（按需补 loading / selected）。→ §8
10. **键盘可达**：一切交互 Tab 可达，焦点顺序符合视觉阅读顺序。→ §9
11. **状态双通道信号**：任何状态差异除颜色外还要有文字或图标——错误、必选、选中不得只变红 / 只变色。→ §1、§8、§9

## 1. 色彩

色板 = 冷灰 `slate` 系 + 语义色，不混暖灰，分三层：中性灰阶（打底与文字）、语义色阶（accent + 四语义族）、档位色阶（五星 → 一星）。

### 中性灰阶

| Token | 色值 | 用途 |
|---|---|---|
| `--bg-page` | `#f8fafc` | 页面底色（浅冷灰；卡片去描边后靠底色衬出白块，勿加深） |
| `--bg-card` | `#ffffff` | 卡片 / 弹窗 / 面板底 |
| `--bg-input` | `#f8fafc` | 输入框底 |
| `--bg-subtle` / `--bg-hover` | `#f1f5f9` | 次级底、悬停高亮 |
| `--border-card` | `#e2e8f0` | 分隔线、历史行边框（卡片本身不用描边） |
| `--border-input` | `#cbd5e1` | 输入框边框 |
| `--text-primary` | `#0f172a` | 主文字 |
| `--text-secondary` | `#475569` | 次级文字（说明、字段标签） |
| `--text-muted` | `#64748b` | 辅助文字（对白底 ≈4.7:1） |
| `--text-on-accent` | `#ffffff` | 重点色底上的文字 |
| `--color-disabled-bg` / `--color-disabled-text` | `#e2e8f0` / `#94a3b8` | 禁用底 / 禁用字 |
| `--icon-muted` | `#aab6c6` | 次要图标静置色，悬停加深为 `--text-muted` |
| `--color-scrim` | `rgba(15,23,42,.4)` | 遮罩层 |

### 语义色阶

每个语义族固定「浅底 → 本体 → 深字」+ 边框，规律统一：

| 语义 | 浅底 `--bg-*` | 边框 `--border-*` | 本体 `--color-*` | 深字 `--color-*-strong` |
|---|---|---|---|---|
| accent（蓝） | — | — | `#1a73e8`（hover `#1765cc` / active `#185abc`） | 白底字直接取 base |
| success 成功（绿） | `#e6f4ea` | `#a8dab5` | `#34a853` | `#0d652d` |
| warning 警告（黄） | `#fef7e0` | `#fde293` | `#fbbc05` | `#b25e00` |
| error 错误（红） | `#fce8e6` | `#f6aea9` | `#ea4335` | `#c5221f` |
| info 信息（蓝） | `#e8f0fe` | `#aecbfa` | `#4285f4` | `#1765cc` |

- rgb 三元组（`--color-accent-rgb: 26, 115, 232` 等）只用于叠透明度处：`rgba(var(--color-X-rgb), …)`（提示条浅底、滚动条滑块、按下底色）。
- **base 与 strong 的分工**：色块 / 进度条 / 按钮底用 base；白底上的色名小字（档位标签、状态文字）必须用 strong，保证对比度。

### 档位色阶（五星 → 一星）

| 档位 | 进度条 / 图形 | 白底档位字 |
|---|---|---|
| 五星 | `--color-success` | `--color-success-strong` |
| 四星 | `--color-accent` | `--color-accent` |
| 三星 | `--color-warning` | `--color-warning-strong` |
| 二星 | `--color-orange` `#f97316` | `--color-orange-strong` `#ea580c` |
| 一星 | `--color-disabled-text` | `--color-disabled-text` |

二星专属橙色只作档位，不作操作 / 警示色；警示一律走 warning 或 error。

### 色彩规则

- 除 `:root` 定义处外，样式表不得出现裸色值；需要新色先加 token 再同步本表。
- 无语义挪用：绿=成功、黄=警告、红=错误、橙=二星，一经建立不再互借。
- 状态不只是颜色（状态双通道）：错误、必选、选中在变色之外另有文字或图标（→§8、§9）。

## 2. 间距（spacing scale）

间距是 **8 网格**：留白、间隙、控件尺寸只取 4（半拍）/ 8 / 16 / 24 / 32 / 48 / 64，不取任意 4 的倍数（12 / 20 / 28 不在网格上，不新造值）。

| Token | 值 | 档位 | 典型用途 |
|---|---|---|---|
| `--space-1` | 4px | 半拍 | 极近邻（图标与字、chip 内距） |
| `--space-2` | 8px | 网格 | 紧凑间隙、列表内距 |
| `--space-4` | 16px | 网格 | 区块间距、面板 padding |
| `--space-6` | 24px | 网格 | 卡片组间、弹窗内距 |
| `--space-8` | 32px | 网格 | 页面级留白 |

**间距同时承担成组**：同组内 4–8、相关组间 16、页面级 24–32。想让某元素重要就放大它周围的间距。例外（不受网格约束）：行高、字号、圆角、图标描边宽、1px 边框。

**点击目标**：可点元素高度 ≥24px，下拉 / 弹窗按钮等主要目标 ≥32px。

## 3. 字号与行高（type scale）

| Token | 值 | 用途 |
|---|---|---|
| `--text-xs` | 12px | 最小辅助标签（版本号、徽标）——底线，不可再小 |
| `--text-sm` | 12px | 小按钮 / chips / 徽标 / 只读值 |
| `--text-md` | 14px | 正文、输入框、默认按钮（软件里大多数文字） |
| `--text-lg` | 16px | 模块标题、弹窗标题、主 CTA 文字 |
| `--text-xl` | 18px | 页头标题、完成页标题与统计大数字 |
| `--text-2xl` | 20px | 预留最大档（暂无在用） |

行高：`--leading-tight 1.3`（标题）/ `--leading-normal 1.5`（正文）/ `--leading-loose 1.8`（长文）。

### 字重（两档制）

**只取 400 常规 / 600 加粗**。微软雅黑只有常规 / 粗两档字形：设 500 会被渲染成 400（无中等字形），600 与 700 渲染相同——故 500 档废弃、700 并入 600。

- **400**：正文、提示、字段标签、普通按钮、步骤标题、列表行名、纯值显示——软件内绝大多数文字。
- **600**：只留给真正要强调的地方——标题（页头 / 模块 / 弹窗 / 完成页）、主 CTA（`.btn--lg`）、分段钮当前项、选中态文字、数字强调（分数 / 统计值 / 步骤号）。
- 加粗用少才有效：需要层次时优先用字号与灰阶（→§0 原则 3），不要靠大范围加粗堆层级。

### 层级公式

- 模块标题 = `lg` / 600 / `--text-secondary`：`.card-title` 与折叠头 `.collapsible-title` 同为「模块标题档」，同级标题不许一大一小。
- 字段标签 = `md` / 400 / `--text-secondary`：`.field-label`（弹窗内 `.dialog-field label` 同档），标签靠次级色与正文 / 输入值区分。
- 主 CTA = `lg` / 600 / accent 实心（`.btn--lg`，站内唯一）；`lg` 只进 ≥40px 高的按钮。
- 一屏内字号档位尽量 2–3 档，别让每个标题都比旁边大一号。

### 字号规则

- 字体默认微软雅黑（`--font-sans`：微软雅黑 UI → 微软雅黑 → Segoe UI），全软件统一，不混第二字体。雅黑只有两档字形，这正是字重两档制的原因。
- 字号收敛为 4 / 2 的倍数，11 / 13px 奇数档废弃。
- 数字数据（分数、人数、进度、统计、步骤号）一律 `font-variant-numeric: tabular-nums`，等宽避免跳动。
- 多行长段落（候选人评分理由）两端对齐 `text-align: justify`，短句不必。
- 中文与字母 / 数字间留空格；夹在中文间的英文标点换中文标点。

## 4. 圆角 / 阴影 / 焦点环 / 滚动条

### 圆角

| Token | 值 | 用途 |
|---|---|---|
| `--radius-sm` | 4px | 内嵌小组件（步骤号、徽标） |
| `--radius-md` | 8px | 输入框、按钮、提示条 |
| `--radius-lg` | 8px | 卡片 |
| `--radius-xl` | 12px | 弹窗、抽屉 |
| `--radius-full` | 999px | 药丸（chips、分段条、状态点、进度条） |

容器取 8（卡片）或 12（弹窗、抽屉），内嵌小组件取 4；`--radius-full` 只留给药丸类，按钮 / 输入框 / 卡片不用全圆。圆角一律走 token，无非档位值。

### 阴影

- 卡片**无描边**，带四向柔和阴影 `--shadow-card = --shadow-sm`（三层：1px 接触线 + 向下近距漫射 + 极淡上沿微影），alpha 刻意调淡（.09/.05/.02），宁浅勿深。
- 浮起层（弹窗 / 下拉 / 抽屉 / Toast）用 `--shadow-md`：偏移与晕影比卡片大一档，层越高影越开。
- 阴影一律叠「阴影灰」`--color-shadow-rgb: 60, 64, 67` 的 alpha（比纯黑暖而低对比）。
- **唯一例外是「状态发光」**：状态点光晕、accent 选中 / 悬停高光、主按钮 hover 影用语义色叠低 alpha，表达「发光 / 选中」，不是浮起层级。

### 焦点环

- 键盘导航 `:focus-visible` 显示 `--ring-color`（accent .35）+ 3px 环；鼠标点击不显示。
- 输入框 `:focus` 用更淡的 `--ring-input`（accent .1），config / overlays 三处同取此 token。
- 一切可 Tab 到的元素必须能看到焦点环。

### 滚动条

- 内容列表框（选岗位 / 候选人 / 岗位描述框）：平时隐藏，鼠标移入才淡出 5px 细条。
- 主界面整页与历史抽屉列表：滚动条一律隐藏，滚轮 / 键盘仍可滚动。

## 5. 动效

| Token | 值 | 用途 |
|---|---|---|
| `--dur-fast` | .15s | 悬停、按下、箭头旋转 |
| `--dur-normal` | .25s | 状态切换、折叠、抽屉遮罩 |
| `--dur-dialog` | .4s | 弹窗遮罩 / 面板进出 |
| `--dur-slow` | .4s | 进度 / 档位条推进 |

缓动：`--ease-out`（.22,1,.36,1）进出场，快进缓出；`--ease-in-out`（.4,0,.2,1）状态切换。

- 时长只取档位；遮罩与面板**同拍进出**（同一档时长），避免「遮罩先到、面板后到」。
- 只动画 `transform` / `opacity` / `width` 等廉价属性，不逐帧改 `top / left`。
- 循环动画周期不入档位（唯一例外）：`spin` 0.8s、`status-pulse` 1.5s、`step-pulse` 1.6s，周期按观感定、缓动仍取 token。
- 已内置 `prefers-reduced-motion` 全局降级。

## 6. 布局与容器

### 页面骨架

- 内容列居中且不随窗口横向铺开：`#app` `max-width:720px`、`margin:0 auto`、`padding:16px 40px`。宽度 ≤720 时整列流式铺满，>720 才触发居中（此上限只在超宽窗口生效）。**只要窗口宽度基准 ≤720，内容就不截断、不重排。**
- 首页纵向节奏：状态栏 → 设置卡 → 运行配置卡之间 `gap:16px`；卡片内控件行距 8px。
- 窗口整体缩放：锁宽高比、内容等比（`electron/window.mjs` 的 `lockAspectRatio` + `setZoomFactor`），不用 `transform: scale` 容器或 CSS `zoom`。设计稿内容区 `DESIGN_W/H` 取 8 网格（当前 656×720），宽高比 = 竖长形。

### 单列优先与多列

- 内容默认一列到底；只有成对控件确有空间才并排：`.run-grid`（岗位 / 数量）、`.greet-controls`（等级 / 按钮）、`.results-stats`（四个数字格）。
- `.run-grid` 用 `minmax(0, 1fr) auto`，岗位格占满、数量列按内容收缩；聊天页不选岗位时退化为单列。

### 渐进披露

- 首页首屏就是「运行配置」，一处可跑通主流程。
- 设置（API / 邮件）收进折叠卡；历史记录是二级入口（抽屉）；岗位增删改走弹窗；危险操作一律经确认弹窗。
- 分支选项条件出现：勾选「完成后自动打招呼」才显示等级下拉；运行中才出现跳过 / 暂停按钮。

### 弹窗 / 抽屉分层

- 叠层按 z-index token：tooltip 100 → dropdown 300 → overlay 1000 → toast 9999。
- 抽屉从左侧滑出；弹窗 / 抽屉内容多时只在自身高度内滚动。

## 7. 图标

- 固定 **Material Symbols** 一套，不混其它图标库；Emoji 与 Unicode 字形（▸ ▾ ✔ ❌）一律不当图标。
- 功能图标统一 **outlined（空心）**；实心只留给少数 CTA 强调。
- 尺寸按场景统一：下拉箭头 12、行内小图标 14、输入框提示 15、按钮内 14–16、成功大勾 28；图标与文字间距 4px。
- 实现：全部画在 `index.html` 顶部 `<symbol>` 库（24 viewBox、`currentColor`），用 `<svg><use href="#icon-…"/></svg>` 引用，界面不散落 `<path>`；方向箭头用 `icon-chevron-*` 由 CSS `rotate()` 转向，不写字形字符。
- 颜色跟随 `currentColor`；需调淡的次要图标统一走 `--icon-muted` 或 `opacity:.75`。
- `icon-resize`（岗位描述框拖拽手柄）是全站唯一内联画线：两条 45° 斜线平行、短线收在右下不越出长线，保持该几何。

## 8. 组件约定

### 状态模型总纲（五态底线）

任何可交互组件都要定义完整状态组：`rest` / `hover` / `active` / `focus-visible` / `disabled`（禁用 = `--color-disabled-*` + `cursor:not-allowed` + 去阴影），按需补 `loading` / `selected`。

- **按压反馈两类**：可整体缩放的控件（按钮、分段钮）按下 `scale(.97–.98)`；行级元素（整行、下拉项、折叠头）用按下底色，不整体缩放。
- **loading**：按钮加载 = 前置转圈动画 + 真正的 `disabled`（置灰、鼠标键盘都点不动），**文字保持不变**——不改成「正在… / …中」。转圈由 CSS `.is-loading::before` 提供，JS 侧统一用 `setLoading(btn, bool)` 开关：它记住进入加载前的禁用状态、结束时还原，可与按条件禁用叠加。
- **selected**：选中态 = 底色 + accent 字双信号（→§9）。

底色约定：输入框用浅灰 `--bg-input`，下拉 / 选择框与卡片用白 `--bg-card`。

| 组件 | 状态要点 | 关键规范 |
|---|---|---|
| **按钮** `.btn` | rest / hover（浅上浮）/ active（scale .98）/ focus-visible / disabled / loading | 变体：`primary`（accent 实心，主 CTA）→ `secondary`（描边）/ `ghost` 次操作 → `danger`（红实心，仅确认弹窗破坏位）。主行动实心、次要描边 / 幽灵，层级一眼可分。尺寸 `btn--sm/lg/block`。文字常规 400，仅 `.btn--lg` 加粗 600。 |
| **输入框** `.input-text` | rest（hover 描边变 accent）/ focus（accent 边框 + 浅环）/ disabled / 错误态（error 边框 + 提示文字或图标） | `--radius-md` / `--border-input` / `--bg-input`。错误不只变红。 |

### 按钮与内文字比例

按钮「身高定字号」，文字不「撑」按钮：

| 按钮 | 高 | 内文字 | 字号/高 |
|---|---|---|---|
| `.btn--sm` | ≈25px | `sm`(12) | 0.48（最小钮，允许） |
| `.btn` 默认 | ≈36px | `md`(14) | 0.39 |
| `.btn--lg` | ≈40px | `lg`(16) | 0.40（上限） |

- `xl`(18) / `2xl`(20) 不进按钮；想让字更大 → 加按钮高度，不是把字塞进矮按钮。
- 按钮内图标边长 ≲ 字号 1.1×，与文字 gap ≥4px。

### 按钮排列：鼓励靠右、危险靠左

- 普通动作（保存 / 确定 / 开始）：主动作放最右，取消在左——如新岗位弹窗「取消 → 保存」。
- 危险动作（删除 / 清空历史）：放**最左**，破坏性按钮被推离惯用点击区，也符合「主 CTA 靠右」；危险确认弹窗里「取消」即鼓励动作，放右侧合理。
- 鼓励动作视觉更实（primary 实心蓝），不与危险按钮做对等的对称样式。

## 9. 无障碍最低清单（改 UI 后自查）

1. **对比度**：正文与重要标签 ≥4.5:1，大字号 / 粗体可放宽到 3:1。已校准：正文 `#0f172a`、次级 `#475569`、辅助 `#64748b`（≈4.7:1）达标。
2. **键盘可达**：全部交互 Tab 可达并用 Enter / 空格 / 方向键操作；弹窗内 Tab 循环、Esc 关闭。
3. **焦点顺序**：Tab 遍历顺序与视觉阅读顺序一致（自上而下、自左而右）。
4. **焦点可见**：键盘导航显示 `--ring-color` 环；鼠标点击不显示；切换页面时程序聚焦的定位标题 / 抽屉（`tabindex=-1`、非交互控件）只是读屏落点，不画环。
5. **不只靠颜色**：错误 = 红描边 + 提示文字 / 图标；必选 = 标识 + 校验提示；选中 = accent 底 + accent 字；连接状态点 = 颜色 + 文字。
6. **读屏**：纯图标按钮有 `aria-label`；装饰图标 `aria-hidden`；展开收起用 `aria-expanded`；动态提示用 live region；弹窗 `role=dialog` + `aria-modal`。
7. **文字可选中**：正文默认可选中复制，仅交互元素 `user-select:none`。
8. **动效可关**：尊重 `prefers-reduced-motion`。

## 11. 新增 / 修改一个 token

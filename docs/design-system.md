# 设计系统（UI 规范）

界面规范单一来源：颜色、间距、字号、圆角、阴影、动效一律取自 `electron/renderer/style.css` 顶部 `:root` 的「设计 token」。改 UI 只引用 token，不写死数值；改 token 同步更新本文件。

界面代码（`electron/renderer/`）：结构 `index.html`、样式 `style.css`、逻辑 `renderer-*.js`（渲染层脚本按功能拆成 10 个小文件，`index.html` 按 `renderer-dom.js → … → renderer-greet.js` 顺序 `<script src>` 引入，共享全局作用域；函数声明全文件可见，DOM 引用只在 `renderer-dom.js` 顶部）。

---

## 0. 三条设计原则

1. **工具优先**：给 HR 长时间使用的效率工具——密度中等偏紧凑、常用操作一屏放下、全程可键盘走完。
2. **一个重点色**：界面只有一个品牌重点色（蓝）；绿 / 黄 / 红 / 橙只表达语义（成功 / 警告 / 错误 / 档位），不作装饰。
3. **状态完整**：可交互元素四态齐全（默认 / 悬停 / 按下 / 禁用）；键盘可到达处必有焦点环。

## 1. 色彩

所有颜色都是冷灰 `slate` 系 + 语义色，不混暖灰。

### 中性色（打底与文字）

| Token | 色值 | 用途 |
|---|---|---|
| `--bg-page` | `#f5f7fa` | 页面底色（偏浅冷灰：卡片去掉描边后靠底色衬出白块，别用太深） |
| `--bg-card` | `#ffffff` | 卡片 / 弹窗 / 面板底 |
| `--bg-input` | `#f8fafc` | 输入框底（比卡片略灰以区分） |
| `--bg-subtle` / `--bg-hover` | `#f1f5f9` | 次级底、悬停高亮（同一灰） |
| `--border-card` | `#e2e8f0` | 边框 token：卡片已不用描边，仍用于分隔线 / 历史行边框等轻分隔 |
| `--border-input` | `#cbd5e1` | 输入框边框 |
| `--text-primary` | `#0f172a` | 主文字（标题、正文） |
| `--text-secondary` | `#475569` | 次级文字（说明、分组标题） |
| `--text-muted` | `#64748b` | 辅助 / 次要文字（对白底 ≥4.6:1） |
| `--text-on-accent` | `#ffffff` | 重点色底上的文字 |
| `--color-disabled-bg` / `--color-disabled-text` | `#e2e8f0` / `#94a3b8` | 禁用底 / 禁用字 |
| `--icon-muted` | `#aab6c6` | 次要图标静置色（如输入框清除按钮圆底），悬停加深为 `--text-muted` |
| `--color-scrim` | `rgba(15,23,42,.4)` | 遮罩层 |

### 语义色（重点色 / 状态）

每个语义家族固定给四档 + 一组 rgb 三元组，规律统一：

| 语义 | 浅底 `--bg-*` | 边框 `--border-*` | 本体 `--color-*` | 深字 `--color-*-strong` |
|---|---|---|---|---|
| 重点 accent（Google 蓝，纯色） | — | — | `#1a73e8`（hover `#1765cc` / active `#185abc`） | `#1a73e8` 字色多用 base，白底不浅化 |
| 成功 success（绿） | `#e6f4ea` | `#a8dab5` | `#34a853` | `#0d652d` |
| 警告 warning（黄） | `#fef7e0` | `#fde293` | `#fbbc05` | `#b25e00` |
| 错误 error（红） | `#fce8e6` | `#f6aea9` | `#ea4335` | `#c5221f` |
| 信息 info（蓝） | `#e8f0fe` | `#aecbfa` | `#4285f4` | `#1765cc` |

- rgb 三元组（`--color-accent-rgb: 26, 115, 232` 等）只在需要透明度（`rgba(var(--color-X-rgb), .x)`）时使用，如提示条、滚动条。
- **重点色只此一套纯色 `#1a73e8`，不用渐变**：hover `#1765cc`、active `#185abc` 已各成 token；旧 `#2563eb` / 渐变方案已废弃。
- **语义色全族统一取 Google 色**（不只重点蓝）：绿 `#34a853` / 黄 `#fbbc05` / 红 `#ea4335` / 信息蓝 `#4285f4`（各配 Google 深字 strong、浅底 bg、边框 border），旧 emerald `#10b981` 系等已废弃。
- **什么时候用 base、什么时候用 strong**：色块、进度条、按钮底用 base；白底上的色名小字（档位标签等）必须用 strong，保证对比度达标（如 `--color-warning-strong` 而非 `--color-warning`）。

### 档位色（五星 → 一星）

打分档位与语义色对齐：**图形 / 进度条用 base，白底档位字用 strong**。

| 档位 | 进度条 | 档位文字 |
|---|---|---|
| 五星 | `--color-success` | `--color-success-strong` |
| 四星 | `--color-accent` | `--color-accent` |
| 三星 | `--color-warning` | `--color-warning-strong` |
| 二星 | `--color-orange` `#f97316` | `--color-orange-strong` `#ea580c` |
| 一星 | `--color-disabled-text` | `--color-disabled-text` |

二星专属橙色 `--color-orange` 只用于档位，**不作操作 / 警示色**；警示一律走 warning（黄）或 error（红）。

### 色彩规则

- **除 `:root` token 定义处之外，样式表不得出现裸色值**（hex / rgb / rgba）。需要新色 → 先加 token。
- 状态语义（成功 / 警告 / 错误）一旦建立就固定对应，不要用绿表示「错误」或反过来。
- 重点色只允许蓝色这一个 family；不要引入第二个彩色 accent 抢视觉。

## 2. 间距（8px / 4px 原则）

间距使用 **4px 节奏**：任何留白、间距都取 4 的倍数，元素尺寸尽量落在 8px 网格上。

| Token | 值 | 典型用途 |
|---|---|---|
| `--space-1` | 4px | 极近邻（图标与字、chip 内距） |
| `--space-2` | 8px | 紧凑间隙、列表内距 |
| `--space-3` | 12px | 常规间隙、行内 padding |
| `--space-4` | 16px | 区块间距、面板 padding |
| `--space-5` | 20px | 大间距 |
| `--space-6` | 24px | 卡片组间、弹窗内距 |
| `--space-8` | 32px | 页面级留白 |

### 间距规则

- 组件间隙、内边距一律用 `var(--space-*)`，不要出现 3 / 5 / 7px 这类非 4 倍数间距。
- 点击目标：小控件可 24–28px 高、周围留足内距，**任何可点元素不小于 24px**；下拉 / 弹窗按钮等主要目标 ≥32px。
- 例外（不受间距网格约束）：行高 `--leading-*`、字母间距、字号、圆角、图标描边宽度、1px 边框。

## 3. 字号与行高

| Token | 值 | 用途 |
|---|---|---|
| `--text-xs` | 12px | 版本号、辅助标签（最小档，不可再小） |
| `--text-sm` | 12px | 小按钮 / chips / 徽标 / 只读值（输出路径） |
| `--text-md` | 14px | 正文默认、输入框、默认按钮（软件里大多数文字） |
| `--text-lg` | 16px | 模块标题（`.card-title` / 折叠卡标题）、弹窗标题、主按钮「开始提取分析」文字 |
| `--text-xl` | 18px | 页头标题、完成页标题（全部完成）与统计数字 |
| `--text-2xl` | 20px | 预留最大档（暂无在用，超大庆祝标题如需要时启用） |

> 注：档位曾在 2026-09-07 先随「页面收窄方案 A」整体上移（正文 14→16、标题随档 +2），同日因「字号太大」回调一档至本表（正文 14、标题 16/18/20），不再放大。

行高：`--leading-tight 1.3`（标题）/ `--leading-normal 1.5`（正文）/ `--leading-loose 1.8`（长文）。

### 字号规则

- 默认字体思源黑体（`--font-sans` 依次回退 Noto Sans CJK SC → 微软雅黑 UI → 微软雅黑），全软件统一，不混第二字体。
- 字号收敛为 **4 / 2 的倍数**：正文默认 14px、最小 12px（曾短暂试行 16 后因「字号太大」回调，勿再放大）；旧 11 / 13px 奇数档已废弃，不再使用。
- 标题字重 600，正文 400，列表名 500 —— 只用 400 / 500 / 600 / 700 四档，不引入更细更粗。
- 层级用「字号 + 字重」一起分（不只靠颜色）：模块标题 `.card-title` 与折叠头 `.collapsible-title` 统一「模块标题档」= `lg` / 600 / `--text-secondary`，同级不许一大一小；字段标签 `.field-label` 为 `md` / 500。
- 数字数据（分数、人数、进度、统计）一律 `font-variant-numeric: tabular-nums`，等宽数字避免跳动。
- 中文排版的字母间用空格或窄空格分隔；夹在中文之间的英文标点换成中文标点（「,」→「，」）。

## 4. 圆角 / 阴影 / 焦点环 / 滚动条

### 圆角

| Token | 值 | 用途 |
|---|---|---|
| `--radius-sm` | 4px | 小徽标、内嵌小组件、步骤编号 |
| `--radius-md` | 8px | 输入框、按钮、提示条 |
| `--radius-lg` | 8px | 卡片（`--radius-card` 别名同值） |
| `--radius-xl` | 12px | 弹窗、抽屉 |
| `--radius-full` | 999px | 药丸（chips、分段条、连接状态点） |

规律：**圆角收敛到 4 / 8 / 12 三档**，不再用 6px；容器取 8（卡片）或 12（弹窗、抽屉），内嵌小组件取 4。
风格取向：**不喜欢大圆角，也不要完全直角**——整体克制在 4–12px，不出现 16px+ 的「很圆」容器；`--radius-full`(999px) 只留给药丸类（chips、分段条、状态点、进度条），普通按钮 / 输入框 / 卡片一律不用全圆、也不做 0px 直角。

### 阴影

- 卡片**无描边**，带极柔阴影 `--shadow-card = --shadow-sm`（0-1px 贴身 + 0-2px 外扩、低透明）——白块既靠底色衬出、又有一层薄浮起，避免两卡纯平难分（2026-09-07 用户反馈恢复）。
- `--shadow-md`（`0 4px 12px …`）——弹窗、浮层、下拉。
- 阴影一律用黑色低透明度，不引入彩色阴影；卡片不叠加实边框。

### 焦点环

- 键盘导航：`button:focus-visible` 等显示 `--ring-width 3px` 的 `--ring-color rgba(26,115,232,.35)` 环。
- **鼠标点击不显示焦点环**（`:focus-visible` 天然区分），输入框各自有 `:focus` 样式。
- 任何可 Tab 到的元素必须能看到焦点环，这是无障碍底线。

### 滚动条

- **内容列表框**（选岗位 / 候选人列表 / 岗位描述编辑框）：平时隐藏，鼠标移入才淡出 5px 细条（滑块 `rgba(100,116,139,.2)`，悬停 `.45`）。
- **主界面整页与历史抽屉列表**：滚动条一律隐藏，滚轮 / 键盘仍可滚动。

## 5. 动效

| Token | 值 | 用途 |
|---|---|---|
| `--dur-fast` / `--transition-fast` | `.15s` | 悬停、按下、箭头旋转 |
| `--dur-normal` | `.25s` | 常规状态切换 |
| `--dur-dialog` | `.32s` | 弹窗淡入淡出 |
| `--dur-slow` | `.4s` | 进度条宽度推进 |

缓动：反馈类用 `--ease-in-out`；进出场用 `--ease-out`（快进缓出更自然）。

### 动效规则

- 反馈类（hover / active / 颜色 / 展开箭头）≤ 200ms；弹窗进出 320ms；进度推进 400ms。
- 弹窗 / 抽屉的**遮罩与面板同拍进出场**（同档时长、同起同止）：弹窗遮罩 `--dur-dialog`(0.32s)、抽屉遮罩 `--dur-normal`(0.25s)，避免「遮罩先到、面板后到」。
- 只动画 `transform` / `opacity` / `width` 等廉价属性，不逐帧改 `top/left`。
- 新增动效一律套上面档位，不自定义时长；如未来做全局降动效，加 `@media (prefers-reduced-motion)` 关掉过渡即可。

## 6. 图标

**选型（一套库、同一风格）**

- 本产品固定用 **Material Symbols** 这一套图标库（Google 官方体系）：全站功能图标只在这套内取，不混入其它库（Feather / Phosphor / Lucide / 手绘等一律不引）。
- 功能图标统一 **outlined（空心）** 变体，五轴参数全站一致：`weight` 400、`grade` 0、`optical size` 随渲染尺寸、`fill` 默认 **0**——只有需要实心强调的（选中、星级等）才 `fill=1`。**仅有的实心功能图标**（CTA 强调例外）：「开始提取分析」的播放键 `icon-play` 与「跳过提取」的 `icon-skip`（均 `fill=1`，同 v1.9.11 时期）；其余功能图标一律空心 outline。
- 同一套内**线宽 / 视觉粗细 / 间距统一**：除上文两只 CTA 实心（`icon-play` / `icon-skip`）外，不实心、空心混用，不粗细混用。
- 图标**尺寸与间距统一**：同场景图标渲染尺寸一致（下拉箭头 12、行内小图标 14、输入框 / 提示 15、按钮内 16、成功大勾 28），图标与文字间距 `--space-1`(4px)；同一按钮、同一行内不得大小不一。
- **禁止**：Emoji 当功能图标；Unicode 字符当图标（▸ ▾ ✔ ❌ 这类字形不是图标）；为省事临时现画 SVG 塞进界面。
- 找不到所需图标时，在同一套里选**近义图标**顶替，不退而求其次用字符 / Emoji / 自画。

**本软件实现（Material 同套 symbol 库）**

- 全部图标统一画在 `index.html` 顶部 `<symbol>`（24 viewBox、`currentColor` 填充），用 `<svg><use href="#icon-…"/></svg>` 引用；界面里不散落 `<path>` / `<line>`；`icon-resize` 是唯一「内联画线」例外，仅此一处定义。
- 颜色跟随 `currentColor` 继承所在文字 / 按钮；图标独立上色时用语义 token。
- 需要**调淡**的次要图标统一走同一淡化方式：用静置色 `--icon-muted`，或统一 `opacity: .75`，不各自乱调。
- 已收录：`icon-settings`（设置）、`icon-eye-on / icon-eye-off`（密码可见切换）、`icon-info`（提示）、`icon-check`（成功）、`icon-close`（关闭 / 清空 ×）、`icon-play` / `icon-skip`（播放键与「跳过提取」键，实心 `fill=1` CTA 强调）、`icon-pause`（暂停）、`icon-folder`（打开输出目录 / 选择目录）、`icon-refresh`（重试）、`icon-chevron-right` / `icon-chevron-down`（折叠面板、下拉、候选人行的方向箭头）、`icon-resize`（岗位描述编辑框右下角拖拽手柄）。
- **方向箭头一律用这对 chevron svg**（`icon-chevron-right` 展开态由 CSS `rotate(90deg)` 转成向下），不写字形字符 ▸ / ▾ / ▼。
- **新增图标**：先进 `<symbol>` 再引用，沿用同一套符号与描边风格；同库字形若与目标风格不一致（如实心 vs 空心），整批一起换，不混着加。
- **`icon-resize` 手柄画法**（右下角抓握标，文档允许的唯一「内联画线」）：两条 45° 斜线严格平行——长线 (7,19)→(18,8)、短线 (13,19)→(18,14)；短线是长线右下方的缩短回声，两线中点沿公垂线偏移 3 格（居中对齐），短线收在右下角、不越出长线。改它时保持此几何。

### 图标无障碍

- 纯装饰图标：`<svg aria-hidden="true">`。
- 只有图标、没有文字的按钮：必须配 `aria-label`（如 `aria-label="更改输出目录"`），不要依赖 title 悬浮提示。
- 图标与文字同框的按钮：文字可读，图标保持装饰性即可。

## 7. 组件约定

统一的状态要求（除特别注明）：**默认 / hover / active / disabled** 四态齐全，交互反馈用 `--transition-fast`。
- 按压反馈：按钮 / 来源切换等可整体缩放的控件按下 `scale(.97–.98)`；整行、下拉项、折叠头这类行级元素用按下底色（`rgba(var(--color-accent-rgb),.16)` 或 `--bg-subtle`），不整体缩放以免破碎。

底色约定：**输入框用浅灰 `--bg-input`，下拉 / 选择框与卡片用白 `--bg-card`**——新增同类控件照此，不要混用。

| 组件 | 关键规范 |
|---|---|
| **按钮** | `btn btn--primary / btn--secondary / btn--ghost / btn--warning / btn--danger / btn--link`。主操作用 primary（蓝）；次要操作 ghost / secondary；危险删除 danger（红）。图标按钮同尺寸放文字前。加载中按钮内文字变「…中」并禁用。一卡只留一个实心 primary（主 CTA），其余同级操作用 secondary / ghost 弱化。 |
| **输入框** | `--radius-md`、`--border-input`；获得焦点变 accent 边框 + 焦点环；带「眼睛」的可切换明文 / 圆点（图标须与框垂直居中，两态位置一致不跳动）。 |
| **只读路径框（输出目录）** | 值是**只读展示**（同「已添加的岗位名」的只读区分法），不许长得像能输入的框：底色加深为 `--bg-subtle`、**无描边**、字色 `--text-muted`、字号 `--text-sm`(12px)，比上方输入框明显弱一档；高度固定 **24px**（8px 网格）。框内右侧放操作图标（文件夹按钮与密码框眼睛按钮共用 `.field-icon-btn` 几何基类：绝对定位不撑高框体，右距统一 `right:10px`，文字右侧留位 32px）；长路径框内省略号收尾，不把整行撑变形。 |
| **选择 / 开关** | 下拉用 `custom-select`（原生 select 改造统一样式）；菜单朝上展开时箭头旋转 180° 指向菜单；开关 / 勾选用 checkbox 样式，选中态 accent。 |
| **弹窗 dialog** | `--radius-xl`、`--shadow-md`、遮罩 `--color-scrim`，`--dur-dialog` 淡入淡出；标题 + 正文（说明后果）+ 底部主次按钮（危险操作 danger 放左、取消放右）。键盘：Esc 取消、Tab 圈内循环。 |
| **提示条 alert** | 语义浅底 `--bg-success/warning/error/info` + 深字正文，**不带描边**（浅底即区分）；可折叠「运行提示」即浅黄卡片。 |
| **徽标 badge / chip** | 连接状态等小圆点用语义色（绿=正常 / 黄=连接中 / 红=未连接），且**文字状态同时在**，不只靠颜色；配置状态徽标「✓ 已设置 / 未设置」用勾 + 文字。 |
| **进度条 / 档位条** | 细高药丸分段条（`--radius-full`）；档位颜色见第 1 节档位色表，附人数与百分号文字。 |
| **步骤条** | ①②③ 三步流程：当前步 accent 高亮转圈，未到步灰。数字 + 说明文字一起给状态。 |
| **候选人列表行** | 行 hover 浅灰高亮；整行可点，展开箭头右侧旋转 90°；名称超长省略号，分数 `tabular-nums` 不跳字；完成页列表 `max-height:200px`（约 5 名半），超出内部滚动。 |
| **统计块** | 完成页统计：提取人数 / 通过人数 / 平均分 / 通过率，数字 `tabular-nums` + 大号字重，配档位分布条。 |
| **抽屉（历史记录）** | 从左侧滑出，右侧遮罩空白处点击或按 Esc 关闭（右上无关闭 ×）；标题栏 + 可滚动列表 + 底部操作区；空态居中一句「暂无历史记录。」；删除 / 清空操作带确认弹窗说明后果。 |
| **折叠面板（设置）** | 折叠后仍显示状态徽标（已设置 / 未设置），展开是表单；折叠态一屏放得下，不出现右侧滚动条。 |

> 具体类名与实现以当前代码为准，新增组件时沿用上述命名与状态惯例。

### 按钮排列：鼓励靠右，危险靠左

底部操作栏或弹窗里的多个按钮，从左到右按「危险 / 退出 → 次动作 → 主 / 鼓励动作」排，**最右永远是希望用户去按的那个**：

- 普通动作（保存 / 确定 / 开始 / 发送）：主动作放**最右**，取消 / 次要动作在它**左边**——如新岗位弹窗是「取消 → 保存」，保存靠右。
- 危险动作（删除 / 清空历史记录）：危险按钮放**最左**、取消 / 安全动作靠右——破坏性按钮被推离惯用的右侧点击区，也不抢「主 CTA 靠右」的位置；危险弹窗里「取消」就是鼓励动作，放右侧合理。
- 不把鼓励按钮和危险按钮做成并排对等的对称样式；一眼能分出主次，鼓励按钮视觉更实（primary 实心蓝）。
- 危险动作按钮是**实心红底白字** `.btn--danger`，只出现在确认弹窗的破坏性「确定」位（弹窗内危险左、取消右），普通界面不放红底大按钮。
- 蓝字 `.btn--link` 已不用于普通按钮（全站无在用的蓝色 link）；仅剩两只红色危险文字钮——抽屉底部「清空历史记录」与历史行内「删除」——用 `.btn--link-danger` 叠出。

### 首页运行配置卡的布局约定（v1.10+）

- **主按钮**：主 CTA「开始提取分析」=`btn--primary btn--lg btn--block`（整卡唯一实心大按钮，16px = `--text-lg`，比正文 14px 大 2px、纵向 padding 9px 控制高度）；重新评分不放首页，走「历史记录」行的「评分」入口。
- **岗位格弹性变宽**：`.run-grid` 两列 `minmax(0,1fr) auto`，岗位格占满剩余宽、数量列按内容收缩；聊天页不选岗位时加 `.has-job` 前删除 → 单列 `minmax(0,1fr)`（由 renderer 在来源切换时同步 class）。
- **自动打招呼选项与模拟复制同行**：`.config-opts-row` 左对齐、不换行；「开启模拟复制提取」的 i 图标之后紧跟 `.auto-greet-section`（同排），勾选框与等级下拉 `.auto-greet-controls` 在同一行顺序排开；`.config-opts-row` 固定 min-height，勾选 / 取消只显示 / 隐藏下拉，不改变行高，也不影响下方「开始提取分析」按钮的位置。
- **「保存设置」在折叠卡 body 底部右对齐**（`.collapsible-actions`），折叠头只留图标 + 标题 + 箭头，不再放保存按钮。
- **页面四周留白**：`#app` 横向内边距 44px、竖向 16px（全宽容器下等效 v1.9.11 的左右舒适留白，卡片不贴边）；首页状态栏 → 设置卡 → 运行配置卡的纵向间距 16px（`--space-4`）。
- **输入框高度**：「选择岗位」与「提取数量」显式等高 **40px**（8px 网格）。
- **执行进度页布局**：模块标题下方步骤等距 12px 靠上排列；主按钮（取消运行）紧跟步骤 3、**不贴底**——多出的留白落到页面底部（用户偏好「有空白就有空白」）。

### 窗口与整体缩放（main.mjs）

- 窗口**锁定宽高比**（等比放大缩小）：`lockAspectRatio()` 用「窗口尺寸 - 内容尺寸」的固定帧差值补偿后 `setAspectRatio`，保证内容区严格为设计稿 660:730，拖边角整体等比缩放、拉不成扁 / 瘦形状。
- 内容用 `webContents.setZoomFactor(f)` 等比缩放：`zoom = clamp(0.7–1.5, min(内容宽/660, 内容高/730))`；锁比例后内容两个方向同时铺满、无白边。最大化由系统接管比例，出现留白属预期。
- **不要用** `transform: scale` 容器或 CSS `zoom` 实现整体缩放；初始尺寸按屏幕工作区自动算。
- 页面容器 `#app`：默认窗口 CSS 视口为设计稿 660 宽，`#app` 占满整宽、`max-width:720px`（上限只在最大化 / 超宽窗口生效，避免拉得过宽）；容器横向内边距 44px、竖向 16px，给卡片与窗口边缘留足呼吸。

## 8. 无障碍最低清单（改动 UI 后自查）

1. **对比度**：正文与重要标签 ≥ 4.5:1，大字号 / 粗体可放宽到 3:1。已校准：正文对白底 `#0f172a`、次级 `#475569`、辅助 `#64748b`（≥4.6:1）均达标；档位字用 strong 一档。
2. **键盘**：全部交互可 Tab 到达并用 Enter / 空格 / 方向键操作，弹窗内 Tab 循环、Esc 关闭。
3. **焦点可见**：键盘导航时出现 `--ring-color` 焦点环；鼠标点击不显示。
4. **读屏**：图标按钮有 `aria-label`；装饰图标 `aria-hidden="true"`；展开/收起元素用 `aria-expanded`；进度、保存成功等动态提示用 live region（toast）。
5. **颜色不是唯一信号**：任何状态差异都同时有文字或形状（如档位同时有★数量与档名、连接状态有文字）。
6. **文字可选中**：界面正文默认可选中复制（错误信息、地址等需要复制），仅交互元素保留 `user-select: none`。

## 10. 新增 / 修改一个 token 的流程

1. 在 `style.css` 的 `:root` 里加值并写注释说明用途；
2. 同步更新本文件对应的表格；
3. 若是语义色，补齐整套（浅底 `--bg-*` / 边框 `--border-*` / 本体 `--color-*` / 深字 `--color-*-strong` / 需要透明度再补 `--color-X-rgb`），保持规律一致；
4. 替换引用处，删掉旧裸值。

# 设计系统（UI 规范）

界面规范单一来源：颜色、间距、字号、行高、圆角、阴影、焦点环、动效时长、z-index 一律取自 `electron/renderer/tokens.css` 顶部 `:root` 的「设计 token」。改 UI 只引用 token，不写死数值；改 token 必须同步更新本文件对应表格。

样式已按原 `style.css` 内部顺序拆成 **6 个 CSS 文件**（`index.html` 中 `<link>` 的排列顺序 = 拆分前的文件内顺序，**勿调换**，否则级联结果变化）。级联顺序的唯一权威是 `index.html` 里的 `<link>` 顺序：

| 文件 | 内容（按文件内 `/* ===== 分节 ===== */` banner） |
|---|---|
| `tokens.css` | `:root` 全部设计 token（字体 / 字号 / 间距 / 色彩 / 圆角 / 阴影 / 焦点环 / 时长缓动 / z-index） |
| `base.css` | reset、滚动条策略、`button` 重置、键盘焦点环、`#app` 页面壳 |
| `topbar.css` | 页头标题与版本号、`.state` 状态容器、Chrome 状态栏（含 `status-pulse`） |
| `config.css` | 首页配置区控件：岗位选择 / 搜索 / 添加弹窗、Card、Field、Toggle、Alert、空态、Hint、Count、模拟复制、Auto Greet、Custom Select、按钮体系、Collapsible、Input Text、Output Row |
| `run.css` | 执行进度步骤条（Step Items / Running Actions）、结果头 / 摘要 / 错误、批量打招呼 |
| `overlays.css` | Modal / Confirm 弹窗、Toast、全局关键帧与 reduced-motion、完成页结果可视化、历史记录抽屉 |

> 拆分纯按源文件顺序「分桶」，不是按组件语义归属——某选择器具体在哪，按各文件内的分节 banner 检索即可，勿按「文件名 = 功能」倒推。组件可用性判断仍以 tokens.css 的 token 与本文档组件约定为准。

界面代码（`electron/renderer/`）：结构 `index.html`（含图标 `<symbol>` 库）、样式 = 上表 6 个 CSS、逻辑 = `renderer-*.js` 10 个小文件（`index.html` 按 `renderer-dom.js → … → renderer-greet.js` 顺序 `<script src>` 引入，共享全局作用域；函数声明全文件可见，DOM 引用只在 `renderer-dom.js` 顶部）。

## 0. 设计原则（总纲）

以下原则是本文档各节的依据，每条指向落点；新改 UI 先对照此纲：

1. **工具优先**：面向 HR 长时间使用的效率工具——密度中等偏紧凑，常用操作一屏放下，默认键盘可达（鼠标为主、键盘不缺失）。
2. **色彩是语义系统**：整套色板 = 中性灰阶 + 唯一重点 accent + 语义色阶（成功 / 警告 / 错误 / 信息）+ 档位色阶；颜色一律来自 token，**无语义挪用、无裸值**。→ §1
3. **只有一个重点色**：accent 蓝是唯一品牌强调色，其余彩色只表达语义或档位，不抢视觉。→ §1
4. **层级由尺寸主导**：越大越重要，辅以字重与灰阶；颜色不作唯一层级信号。→ §3、§1
5. **间距走 8 网格**：间距/尺寸取档位 4（半拍）/ 8 / 16 / 24 / 32 / 48 / 64——以 8 的倍数为主，不取任意 4 的倍数（12 / 20 / 28…不在网格上）。→ §2
6. **留白即层级**：重要的东西周围要「空」——用留白把焦点让给核心内容，宁可空着也不要硬塞。→ §2、§6
7. **邻近成组（Gestalt proximity）**：相关内容放一起自动成组，无关内容用间距分开——分组靠间距，不靠描边线框。→ §2、§6
8. **单列优先**：内容默认一列到底，横向空间确有余量才升级为多列，不硬塞并排。→ §6
9. **渐进披露**：核心内容最先出现、开箱即用；次要 / 高级内容收进折叠卡、二级页，不摊在首页。→ §6、§8
10. **状态模型完整**：可交互组件至少五态齐全——静置 / 悬停 / 按下 / 键盘聚焦 / 禁用（按钮、输入框、卡片、开关、菜单项通用；视组件按需补 loading / selected）。→ §8
11. **键盘可达**：一切交互 Tab 可达，焦点遍历顺序符合视觉阅读顺序（自上而下、自左而右）。→ §9
12. **状态双通道信号**：任何状态差异除了颜色还要有文字或图标 / 形状——错误、必选、选中不得只变红 / 只变色。→ §1、§8、§9

## 1. 色彩

所有颜色都是冷灰 `slate` 系 + 语义色，不混暖灰。色板分三层：**中性灰阶**（打底与文字）、**语义色阶**（accent + 四语义族）、**档位色阶**（五星→一星）。

### 中性灰阶（打底与文字）

| Token | 色值 | 用途 |
|---|---|---|
| `--bg-page` | `#f5f7fa` | 页面底色（偏浅冷灰：卡片去描边后靠底色衬出白块，别用太深） |
| `--bg-card` | `#ffffff` | 卡片 / 弹窗 / 面板底 |
| `--bg-input` | `#f8fafc` | 输入框底（比卡片略灰以区分） |
| `--bg-subtle` / `--bg-hover` | `#f1f5f9` | 次级底、悬停高亮（同一灰） |
| `--border-card` | `#e2e8f0` | 轻分隔：卡片不用描边，此 token 用于分隔线、历史行边框 |
| `--border-input` | `#cbd5e1` | 输入框边框 |
| `--text-primary` | `#0f172a` | 主文字（标题、正文） |
| `--text-secondary` | `#475569` | 次级文字（说明、分组标题） |
| `--text-muted` | `#64748b` | 辅助 / 次要文字（对白底 ≈4.7:1） |
| `--text-on-accent` | `#ffffff` | 重点色底上的文字 |
| `--color-disabled-bg` / `--color-disabled-text` | `#e2e8f0` / `#94a3b8` | 禁用底 / 禁用字 |
| `--icon-muted` | `#aab6c6` | 次要图标静置色，悬停加深为 `--text-muted` |
| `--color-scrim` | `rgba(15,23,42,.4)` | 遮罩层 |

### 语义色阶（accent + 语义族）

每个语义族固定给「浅底 → 本体 → 深字」三档 + 边框 + 一组 rgb 三元组，规律统一：

| 语义 | 浅底 `--bg-*` | 边框 `--border-*` | 本体 `--color-*` | 深字 `--color-*-strong` |
|---|---|---|---|---|
| accent（重点，蓝） | — | — | `#1a73e8`（hover `#1765cc` / active `#185abc`） | 字色多用 base，白底不浅化 |
| success 成功（绿） | `#e6f4ea` | `#a8dab5` | `#34a853` | `#0d652d` |
| warning 警告（黄） | `#fef7e0` | `#fde293` | `#fbbc05` | `#b25e00` |
| error 错误（红） | `#fce8e6` | `#f6aea9` | `#ea4335` | `#c5221f` |
| info 信息（蓝） | `#e8f0fe` | `#aecbfa` | `#4285f4` | `#1765cc` |

- rgb 三元组（`--color-accent-rgb: 26, 115, 232` 等）只用于需要透明度处：`rgba(var(--color-X-rgb), .x)`（提示条浅底、滚动条滑块、按下底色等）。
- 文字色另有 `--text-primary-rgb: 15, 23, 42` / `--text-muted-rgb: 100, 116, 139`——主 / 辅助文字要叠透明度时用它（tooltip 深底、滚动条滑块、清空按钮圆底）。
- 阴影另有 `--color-shadow-rgb: 60, 64, 67`（谷歌灰 #3C4043）——所有阴影叠它的 alpha，不拿文字色当影色（→§4）。
- **base 与 strong 的分工**：色块、进度条、按钮底用 base；白底上的色名小字（档位标签、状态文字）必须用 strong，保证对比度（如 `--color-warning-strong` 而非 `--color-warning`）。

### 档位色阶（五星 → 一星）

打分档位与语义色对齐；**图形 / 进度条用 base，白底档位字用 strong**。

| 档位 | 进度条 / 图形 | 白底档位文字 |
|---|---|---|
| 五星 | `--color-success` | `--color-success-strong` |
| 四星 | `--color-accent` | `--color-accent` |
| 三星 | `--color-warning` | `--color-warning-strong` |
| 二星 | `--color-orange` `#f97316` | `--color-orange-strong` `#ea580c` |
| 一星 | `--color-disabled-text` | `--color-disabled-text` |

二星专属橙色只作档位，不作操作 / 警示色；警示一律走 warning（黄）或 error（红）。

### 色彩规则

- 颜色全部来自本表 token：除 `:root` 定义处外，样式表不得出现裸色值（hex / rgb / rgba）。需要新色 → 先加 token，再同步本表。
- 无语义挪用：绿=成功、黄=警告、红=错误、橙=二星，一旦建立就固定，不互相借用（绿不表达「错误」，红不作「档位二」…）。
- 重点 accent 只此一套纯色蓝，不用渐变、不引入第二个彩色 accent。
- 状态不只是颜色（状态双通道）：错误输入、必选标记、选中态等在变色之外都要有文字或图标 / 形状，见 §8、§9。

## 2. 间距（spacing scale）

间距是 **8 网格**：留白、间隙、控件尺寸只取档位 **4（半拍）/ 8 / 16 / 24 / 32 / 48 / 64**——以 8 的倍数为主，**不取任意 4 的倍数**（12 / 20 / 28…不在网格上，不新造值）。元素尺寸尽量落在 8px 网格上。

| Token | 值 | 档位 | 典型用途 |
|---|---|---|---|
| `--space-1` | 4px | 半拍 | 极近邻（图标与字、chip 内距） |
| `--space-2` | 8px | 8 网格 | 紧凑间隙、列表内距 |
| `--space-4` | 16px | 8 网格 | 区块间距、面板 padding |
| `--space-6` | 24px | 8 网格 | 卡片组间、弹窗内距 |
| `--space-8` | 32px | 8 网格 | 页面级留白 |
| — | 48 / 64px | 8 网格 | 大版面档（`tokens.css` 尚未定义，需要时补） |

> 12px / 20px 两个旧档（原 `--space-3/5`）已全部收敛为网格档并移除 token：12 → 8 或 16、20 → 16 或 24（面板留白 / 间距走 8 网格）。勿再加回。

### 间距与成组

间距同时承担「邻近性 / 分组」：**同组内小档（4–8），相关组之间中档（16），页面级大档（24–32）**。宁可靠间距拉开分组，也不要为分组加描边线框。留白做层级：想让哪个元素重要，就把它周围的间距放大（→§6）。

### 间距规则

- 组件间隙、内边距一律 `var(--space-*)`。
- 点击目标：可点元素高度不小于 **24px**，小控件（24–28px）四周留足内距；下拉、弹窗按钮等主要目标 ≥**32px**。
- 例外（不受网格约束）：行高 `--leading-*`、字母间距、字号、圆角、图标描边宽度、1px 边框。

## 3. 字号与行高（type scale）

| Token | 值 | 用途 |
|---|---|---|
| `--text-xs` | 12px | 最小辅助标签（版本号、徽标角标）——最小档，不可再小 |
| `--text-sm` | 12px | 小按钮 / chips / 徽标 / 只读值（输出路径） |
| `--text-md` | 14px | 正文默认、输入框、默认按钮（软件里大多数文字） |
| `--text-lg` | 16px | 模块标题、弹窗标题、主按钮文字 |
| `--text-xl` | 18px | 页头标题、完成页标题与统计大数字 |
| `--text-2xl` | 20px | 预留最大档（暂无在用，超大庆祝标题如需要时启用） |

> 已校准收敛：正文 14、辅助 ≥12（12 为底线），勿再放大。曾整体试行更大字号后回调，不再改回。

行高：`--leading-tight 1.3`（标题）/ `--leading-normal 1.5`（正文）/ `--leading-loose 1.8`（长文）。字重只取 **400 / 500 / 600 / 700**：正文 400、列表名 / 标签 500、标题 600。

### 层级公式（type hierarchy）

层级主要由**尺寸**承担——越大越重要（§0 原则 4），辅以字重与灰阶；颜色不作为唯一层级信号：

- 模块标题 = `lg` / 600 / `--text-secondary`：`.card-title` 与折叠头 `.collapsible-title` 同为「模块标题档」，同级组件标题不许一大一小。
- 字段标签 = `md` / 500：`.field-label`。
- 主 CTA 文字 = `lg`（比正文 `md` 大一档），配更实心主色；`lg` 只进 ≥40px 高的按钮，比例见 §8「按钮与内文字比例」。
- 一屏内字号档位尽量少（2–3 档足够），不要每个标题都比旁边大一号。

### 字号规则

- 字体思源黑体（`--font-sans` 依次回退 Noto Sans CJK SC → 微软雅黑 UI → 微软雅黑），全软件统一，不混第二字体。
- 字号收敛为 4 / 2 的倍数，旧 11 / 13px 奇数档废弃。
- 数字数据（分数、人数、进度、统计、步骤号）一律 `font-variant-numeric: tabular-nums`，等宽数字避免跳动。
- 中文与字母 / 数字间用空格隔开；夹在中文间的英文标点换中文标点。

## 4. 圆角 / 阴影 / 焦点环 / 滚动条

### 圆角（radius scale）

| Token | 值 | 用途 |
|---|---|---|
| `--radius-sm` | 4px | 内嵌小组件（步骤编号、徽标） |
| `--radius-md` | 8px | 输入框、按钮、提示条 |
| `--radius-lg` | 8px | 卡片（`--radius-card` 别名同值） |
| `--radius-xl` | 12px | 弹窗、抽屉 |
| `--radius-full` | 999px | 药丸（chips、分段条、状态点、进度条） |

圆角档位 = 4 / 8 / 8 / 12 / full：容器取 8（卡片）或 12（弹窗、抽屉），内嵌小组件取 4。风格克制——不追求大圆角（16px+ 的「很圆」容器），也不要 0px 直角；`--radius-full` 只留给药丸类，普通按钮 / 输入框 / 卡片一律不用全圆。

> 曾有历史遗留非档位 `6px`（岗位选择框、步骤编号、结果提示条、帮助气泡），已全部收敛到档位：选择框/列表与输入同 `8`（radius-input/md）、步骤编号等内嵌小组件取 `4`（radius-sm）、提示条/气泡取 `8`（radius-md）。**圆角一律走 token 档位，无历史例外，勿再出现非档位圆角。**

### 阴影

- 卡片**无描边**，带四向柔和阴影 `--shadow-card = --shadow-sm`（三层：1px 接触线勾边 + 向下近距漫射 + 极淡上沿微影，见 §1 阴影灰）。白块既靠底色衬出、又上下左右都有薄浮起——不只有下方影子（只压下面，卡片像「贴」在底上）。
- `--shadow-md`（`0 2px 4px / 0 6px 14px / 0 -2px 8px`，同相暗调）承载浮起层级：弹窗、浮层、下拉、抽屉、Toast——偏移与晕影比卡片大一档，层越高影越开。
- 阴影一律用「阴影灰」`--color-shadow-rgb: 60, 64, 67`（谷歌灰 #3C4043）叠 alpha：比纯黑暖而低对比，纸感、不脏；卡片不叠加实边框。决策依据：无描边靠底色衬卡、阴影承载浮起层级。
- **彩色影子的唯一例外是「状态发光」**：状态点光晕（`status-dot` 绿/黄/红）、accent 选中/悬停高光与主按钮抬升影（`toggle-btn.active`、`btn--primary:hover` 等）用语义色叠低 alpha，表达的是「发光 / 选中」语义信号，不是浮起层级——浮起一律走上面的阴影灰 `--shadow-*`。新加发光先找已有同类，不各自手调。

### 焦点环（focus ring）

- 键盘导航：`button:focus-visible` 等显示 `--ring-width 3px` 的 `--ring-color rgba(26,115,232,.35)` 环。
- **鼠标点击不显示焦点环**（`:focus-visible` 天然区分）；输入框各自有 `:focus` 样式，不叠加通用环。
- 输入框 `:focus` 浅环走 `--ring-input`（`0 0 0 3px rgba(accent,.1)`，比键盘环淡）：config/overlays 三处输入样式同取此 token，改环宽 / 透明度只动 token 一处。
- 任何可 Tab 到的元素必须能看到焦点环（无障碍底线，→§9）。

### 滚动条

- **内容列表框**（选岗位 / 候选人列表 / 岗位描述编辑框）：平时隐藏细条，鼠标移入框内才淡出 5px 细条（滑块 `rgba(100,116,139,.2)`，滑块悬停 `.45`）；Firefox 用 `scrollbar-width` 兜底。
- **主界面整页与历史抽屉列表**：滚动条一律隐藏，滚轮 / 键盘仍可滚动。

## 5. 动效

| Token | 值 | 用途 |
|---|---|---|
| `--dur-fast` / `--transition-fast` | `.15s` | 悬停、按下、箭头旋转、颜色 |
| `--dur-normal` | `.25s` | 常规状态切换、折叠、抽屉 |
| `--dur-dialog` | `.32s` | 弹窗遮罩 / 面板进出 |
| `--dur-slow` | `.4s` | 进度条 / 档位条宽度推进 |

缓动：`--ease-out`（`.22,1,.36,1`）进出场——快进缓出更自然；`--ease-in-out`（`.4,0,.2,1`）反馈类状态切换。

### 动效规则

- 时长只取档位，不自定义；反馈类（hover / active / 颜色 / 箭头）≤ 200ms，弹窗 320ms，进度推进 400ms。
- 遮罩与面板**同拍进出**（同档时长、同起同止）：弹窗遮罩用 `--dur-dialog`、抽屉遮罩用 `--dur-normal`，避免「遮罩先到、面板后到」。
- 只动画 `transform` / `opacity` / `width` 等廉价属性，不逐帧改 `top / left`。
- **循环节奏不入档位（唯一例外）**：无限动画的周期按观感自定义——`spin` 0.8s `linear`（旋转需匀速）、`status-pulse` 1.5s、`step-pulse` 1.6s；周期不入 .15–.4 档，但缓动仍取 token（step-pulse 用 `--ease-in-out`）。
- 关键帧就近散布：共用的视图 / 弹窗 / 下拉进出场（`state-in` / `overlay-in` / `box-in` / `menu-in` / `step-pulse` / `step-pop` 等）集中在 `overlays.css` 的「全局关键帧」分节；局部动画就近定义（状态栏 `status-pulse` 在 `topbar.css`、Toast 进出场在其分节、`drawer-in` 在历史抽屉分节）。新增动画先找已有同名 / 同族帧复用，不各自新写。
- 已内置 `@media (prefers-reduced-motion: reduce)` 全局降级（关闭全部动画与过渡），尊重系统「减少动态效果」。

## 6. 布局与容器

### 页面骨架

- 内容列居中，宽不随大窗口横向铺开：`#app` `width:100%`、`max-width:720px`、`margin:0 auto`、`padding:16px 40px`、`min-height:100%` 纵向 flex。
  - 横向 40px（5×8，落在 8px 网格）是「舒适余白」，卡片不贴边；竖向 16px 保证一屏装下不溢出。此上限只在最大化 / 超宽窗口生效。
- 首页纵向节奏：状态栏 → 设置卡 → 运行配置卡之间 `gap:16px`（`--space-4`）；卡片内控件行距 8px。
- 执行进度页：标题、三步、按钮紧凑靠上等距 8px（原 12px 旧档收敛）；**按钮不贴底**——下方留白由页面底色承接（「有空白就有空白」）。
- 整体缩放：窗口锁宽高比（内容等比，`electron/window.mjs` 的 `lockAspectRatio` + `setZoomFactor`），不要用 `transform: scale` 容器或 CSS `zoom`。

### 单列优先

- 内容默认**一列到底**；只有并排项确有意义且横向放得下时才用网格，不硬塞。
- 允许的多列都是「成对控件」：运行配置卡 `.run-grid`（岗位 / 数量两列）、打招呼 `.greet-controls`（等级下拉 / 开始按钮两列等宽）、完成页统计 `.results-stats`（四个数字格）。
- `.run-grid` 用 `minmax(0, 1fr) auto`：岗位格占满剩余宽、数量列按内容收缩；聊天页不选岗位时退化为单列 `minmax(0,1fr)`。两格标签行高不同时控件贴底对齐（`align-items:end`）。
- 选项行 `.config-opts-row` 允许自然换行（`flex-wrap`），勾选 / 取消只增删同排下拉，不改变行高——「开始提取分析」按钮只会被顺延，不会被挤压变形。

### 邻近与留白在布局层的应用

- 分组靠间距（§2）：设置卡内字段组与组之间 `16px`，同组内字段间 `8px`；重要元素周围多留白即强调。
- 标题层级用字号分（模块标题 16 / 页头 18），大标题上下留白比小标题宽。

### 渐进披露

- **核心开箱即用**：首页首屏就是「运行配置」，主操作 `开始提取分析` 一处即可跑通。
- **次要收进折叠 / 二级页**：API / 邮件等设置收进折叠卡（`.collapsible-card`，折叠态只露标题 + 状态徽标）；历史记录是二级入口（按钮 → 左侧抽屉）；岗位增删改走弹窗；危险操作一律经确认弹窗。
- 分支选项条件出现：勾选「完成后自动打招呼」才显示等级下拉；运行中才出现跳过 / 暂停按钮。

### 弹窗 / 抽屉分层

- 叠层顺序依 z-index token：tooltip 100 → dropdown 300 → overlay 1000 → toast 9999；添加岗位弹窗置顶于目标岗位弹窗之上（`z-index: calc(var(--z-overlay)+1)`）。
- 抽屉从左侧滑出、右侧留遮罩；弹窗 / 抽屉内容多时只在自身高度内滚动（`overscroll-behavior`），不外溢到遮罩。

## 7. 图标

**选型（一套库、同一风格）**

- 固定 **Material Symbols** 一套（Google 官方体系），不混 Feather / Phosphor / Lucide / 手绘等其它库。
- 功能图标统一 **outlined（空心）**：`weight 400`、`fill 0`；仅两只 CTA 例外做实心强调——`icon-play`（开始提取分析）与 `icon-skip`（跳过提取），为全站仅有的实心功能图标。
- 图标尺寸按场景统一：下拉箭头 12、行内小图标 14、输入框 / 提示 15、按钮内 14–16、成功大勾 28；图标与文字间距 `--space-1`(4px)。同一按钮 / 同一行内大小一致。
- **禁止**：Emoji 当功能图标；Unicode 字符当图标（▸ ▾ ✔ ❌ 这类字形不是图标）；为省事临时现画 SVG 塞进界面。找不到图标时在同一套里选近义项顶替。

**实现（`index.html` 顶部 `<symbol>` 库）**

- 全部图标画在 `<symbol>`（24 viewBox、`currentColor` 填充），用 `<svg><use href="#icon-…"/></svg>` 引用；界面不散落 `<path>` / `<line>`。
- 方向箭头一律用 `icon-chevron-right` / `icon-chevron-down`（展开态由 CSS `rotate(90deg)` 转），不写字形字符。
- 图标颜色跟随 `currentColor` 继承；需调淡的次要图标统一走 `--icon-muted` 或 `opacity:.75`，不各自乱调。
- `icon-resize`（岗位描述编辑框右下角拖拽手柄）是全站唯一「内联画线」例外：两条 45° 斜线严格平行——长线 (7,19)→(18,8)、短线 (14.5,19.5)→(18.5,15.5)，短线中点落在长线的公垂线上（相对居中）；中心距 ≈5.7 单位（12px 渲染 ≈2.8px，紧贴但扫一眼仍能分清是两条）。短线收在右下不越出长线。改它时保持此几何。

## 8. 组件约定

### 状态模型总纲（五态底线）

任何可交互组件定义完整状态组，**通用五态** = `rest`（静置） / `hover`（悬停） / `active`（按下） / `focus-visible`（键盘聚焦，显示焦点环） / `disabled`（禁用：`--color-disabled-*`、`cursor:not-allowed`、去阴影），视组件按需补 `loading`（进行中）/ `selected`（选中）。

- **按压反馈两类**：可整体缩放的控件（按钮、分段钮）按下 `scale(.97–.98)`；整行、下拉项、折叠头这类行级元素用**按下底色**（`rgba(var(--color-accent-rgb),.16)` 或 `--bg-subtle`），不整体缩放以免内容破碎。
- **focus-visible**：键盘到达即显示 `--ring-color` 环；鼠标点击不显示（→§4）。
- **loading**：按钮加载 = 文字变「…中」+ 转圈图标，`pointer-events:none` 防连点。
- **selected**：选中态「底色 + accent 字」双信号（不只变色，→§9）；下拉选中项用 `accent` 色字，与 hover 同底不跳变。

底色约定：**输入框用浅灰 `--bg-input`，下拉 / 选择框与卡片用白 `--bg-card`**——新增同类控件照此，不混用。

| 组件 | 状态要点 | 关键规范 |
|---|---|---|
| **按钮** `.btn` | rest / hover(浅上浮) / active(scale.98) / focus-visible(环) / disabled / loading | 变体分层：`btn--primary`(accent 实心) 主 CTA → `btn--secondary`(描边) / `btn--ghost`(幽灵) 次操作 → `btn--danger`(红实心,仅确认弹窗破坏位) / `btn--warning` / `btn--paused`。主行动实心、次要描边 / 幽灵，层级一眼可分。尺寸 `btn--sm/lg/block`。一卡只留一个实心 primary。图标按钮同尺寸放文字前。 |

### 按钮与内文字比例

按钮是「身高定字号」：字号档位由按钮高度定，不反过来。内文字字号 ≤ 按钮高度的 **~40%**、文字行高块（字号 × 行高）≤ ~56%，四周留白充足、文字不「撑」按钮：

| 按钮 | 高 | 内文字 | 字号/高 |
|---|---|---|---|
| `.btn--sm` | ≈25px | `sm`(12) | 0.48（允许，最小钮） |
| `.btn` 默认 | ≈36px | `md`(14) | 0.39 |
| `#btn-start`（站内唯一 `.btn--lg`） | ≈40px | `lg`(16) | 0.40（已是上限） |

- **`xl`(18) / `2xl`(20) 不进按钮**；想让字更大 → 加按钮高度，不是把字塞进矮按钮里「顶」边框。
- 「开始提取分析」40px 高配 16px 就是规则允许的最大字号占比；此前显得过大 = 字号越过 ~40% 这条线。改动它时先验比例再动。
- 按钮内图标同此：图标边长 ≲ 字号 ~1.1×，不与文字互相挤压（gap ≥ 4px）。

### 按钮排列：鼓励靠右，危险靠左

底部操作栏或弹窗里的多个按钮，从左到右按「危险 / 退出 → 次动作 → 主 / 鼓励动作」排，**最右永远是希望用户去按的那个**：

- 普通动作（保存 / 确定 / 开始）：主动作放最右，取消 / 次要动作在它左边——如新岗位弹窗「取消 → 保存」。
- 危险动作（删除 / 清空历史）：放**最左**、取消 / 安全动作靠右——破坏性按钮被推离惯用点击区，也不抢「主 CTA 靠右」；危险确认弹窗里「取消」即鼓励动作，放右侧合理。
- 不把鼓励按钮和危险按钮做成并排对等的对称样式：鼓励动作视觉更实（primary 实心蓝）。
- 危险按钮是实心红底白字 `.btn--danger`，只出现在确认弹窗的破坏性「确定」位，普通界面不放红底大按钮。蓝字 `.btn--link` 不再用于普通按钮；仅两只红字轻量危险钮（抽屉底部「清空历史记录」、历史行内「删除」）用 `.btn--link-danger`。

## 9. 无障碍最低清单（改动 UI 后自查）

1. **对比度**：正文与重要标签 ≥ **4.5:1**，大字号 / 粗体可放宽到 **3:1**。已校准：正文 `#0f172a`、次级 `#475569`、辅助 `#64748b`（≈4.7:1）均达标；档位字用 strong 一档。
2. **键盘可达**：全部交互可 Tab 到达并用 Enter / 空格 / 方向键操作；弹窗内 Tab 循环、Esc 关闭。
3. **焦点顺序遵循视觉阅读顺序**：自上而下、自左而右——DOM / Tab 顺序与用户看到的顺序一致，不跳焦点。
4. **焦点可见**：键盘导航时出现 `--ring-color` 焦点环；鼠标点击不显示。
5. **不只靠颜色（状态双通道）**：任何状态差异都要同时有文字或形状——错误输入 = 红描边 + 提示文字 / 图标；必选 = 标识 + 校验提示；选中 = accent 底 + accent 字 / 勾；连接状态点 = 颜色 + 文字。给看不到颜色的用户同样的信息。
6. **读屏**：纯图标按钮有 `aria-label`；装饰图标 `aria-hidden="true"`；展开 / 收起用 `aria-expanded`；进度、保存成功等动态提示用 live region（toast `role=status`、`aria-live=polite`）；弹窗 `role=dialog` + `aria-modal`。
7. **文字可选中**：界面正文默认可选中复制（错误信息、路径等要能复制），仅交互元素保留 `user-select:none`。
8. **动效可关**：`prefers-reduced-motion` 时关闭动画与过渡（已内置，→§5）。

## 11. 新增 / 修改一个 token 的流程

1. 在 `tokens.css` 的 `:root` 里加值并写注释说明用途；
2. 同步更新本文件对应表格；
3. 若是语义色，补齐整套（浅底 `--bg-*` / 边框 `--border-*` / 本体 `--color-*` / 深字 `--color-*-strong`；需要透明度再补 `--color-X-rgb`），保持规律一致；
4. 替换引用处，删掉旧裸值；`npm start` 目测确认。

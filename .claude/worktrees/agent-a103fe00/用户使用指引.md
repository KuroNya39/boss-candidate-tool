# Boss 直聘候选人提取工具 - 使用指引

## 一、环境准备（只需做一次）

### 1. 安装 Node.js 22+

- 安装后打开 PowerShell 跑 `node -v` 确认版本 ≥ 22

### 2. 配置 Chrome 远程调试

- 打开 Chrome，地址栏输入：`chrome://inspect/#remote-debugging`
- 勾选 **"Allow remote debugging for this browser instance"**
- 重启 Chrome
- **登录 Boss 直聘招聘端**

### 3. 安装 Claude Code


## 二、安装这个工具

### 1. 解压 zip

把 `web-access-trial.zip` 解压到任意目录，例如 `D:\tools\web-access-trial`

> ⚠️ 路径不要包含中文和空格

### 2. 注册为 Claude Code 插件

  1. 添加插件源
``` 
  claude plugins marketplace add <项目目录>（例如："D:\tools\web-access-trial"）
``` 
  2. 安装插件
``` 
  claude plugins install my-web-access
``` 
  3. 验证
``` 
  claude plugins list
``` 

  看到 my-web-access 即注册成功。重启 Claude Code 后在任意目录下输入 / 可看到相关条目。


## 三、开始使用（在 Claude Code 里对话）

直接用**自然语言**让 Claude 调用工具。

### 场景 1：提取候选人

> 例：帮我从 Boss 直聘提取前 20 个候选人，包括在线简历全文

Claude 会：
1. 自动检查环境（首次会提示你配置 Chrome 调试端口）
2. 启动后台代理
3. 打开 Boss 页面、逐个提取简历（截图 + OCR）
4. 结果写入 `output/zhipin-candidates.json`

### 场景 2：筛选评分

> 例：帮我对候选人并打分

> 例：帮我筛选出"2 年以上 Java 经验"的候选人并打分

Claude 自动生成筛选规则、评分、导出 Excel 到 `output/candidates.xlsx`。

## 四、注意事项

| 项 | 说明 |
|---|---|
| 重复运行 | 每次运行会自动把老的 `output/` 归档到 `output-YYYYMMDD-HHMM/`，不会覆盖 |
| 断点恢复 | 意外中断后对 Claude 说「恢复上次提取」，会从进度继续 |
| 在线简历 | Canvas 渲染，用截图 + OCR 提取，可能有少量识别误差（不影响整体评估）|
| 并非所有候选人都有在线简历 | 脚本会自动跳过 |
| 别在脚本运行时手动操作 Boss 页面 | 避免 DOM 定位冲突 |
| 离线可用 | OCR 语言包已内置（`ocr-lang/`），无需联网下载 |

## 五、常见问题

**Q：Claude 提示「CDP Proxy 未启动」**
A：检查 Chrome 是否勾选了 `Allow remote debugging`，然后重启 Chrome。

**Q：提取到一半停了**
A：对 Claude 说「继续上次的提取」即可恢复。

**Q：想清空重来**
A：删除 `output/` 目录即可。历史归档在 `output-20260424-1530/` 里，可以单独删除。

**Q：输出文件在哪**

- `output/zhipin-candidates.json` — 原始结构化数据
- `output/candidates.xlsx` — Excel 表格（含基础信息 + 在线简历）
- `output/resumes/*.png` — 简历截图
- `output/resumes/*.txt` — OCR 文本

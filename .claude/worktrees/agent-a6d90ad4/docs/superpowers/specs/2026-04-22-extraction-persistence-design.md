# 提取结果持久化设计

## 版本历史

| 版本 | 日期 | 变更 |
|------|------|------|
| v1 | 2026-04-22 | 初版 |

## 背景

当前 BOSS 直聘候选人提取功能工作正常，但提取结果仅输出到对话中。用户需要：
1. 将结果保存到文件，方便后续筛选打分
2. 避免每次手动复制粘贴

**尝试过的方案**：在站点经验的"使用流程"末尾添加保存指令，但 LLM 容易忽略。

**原因分析**：
1. 使用流程有 9 个步骤，LLM 注意力集中在 DOM 操作上
2. 后处理指令与核心任务（提取数据）分离，被"任务完成"判断覆盖
3. 没有明确的触发机制让 LLM 意识到"保存是必须的"

## 目标

设计一种机制，让提取结果自动保存到文件，且 LLM 不会忽略保存行为。

## 方案：主文档定义持久化规范

### 核心思路

1. **触发器**：站点经验文件的 frontmatter 定义 `outputFile` 字段
2. **规范定义**：SKILL.md 主文档定义保存行为
3. **执行时机**：整合到"汇总输出"核心步骤中

### 设计详情

#### 1. SKILL.md 新增章节

在主文档中新增"提取结果持久化"章节：

```markdown
## 提取结果持久化

当站点经验文件定义了 `outputFile` 字段时，提取结果必须保存到文件。

**触发条件**：站点经验 frontmatter 包含 `outputFile` 字段。

**保存规则**：
| 属性 | 值 |
|------|-----|
| 目录 | `./output/`（自动创建） |
| 文件名 | `outputFile` 字段值 |
| 策略 | 覆盖保存 |
| 格式 | JSON |

**执行时机**：在汇总输出后、向用户展示结果前执行保存。

**流程**：
1. 汇总数据为完整 JSON 结构
2. 检查站点经验是否定义 `outputFile`
3. 若有：
   - 确保 `./output/` 目录存在
   - 将 JSON 写入 `./output/{outputFile}`
4. 向用户输出结果，并告知文件路径

**示例**：

站点经验 frontmatter：
```yaml
---
domain: zhipin.com
outputFile: zhipin-candidates.json
---
```

提取完成后输出：
```
已提取 5 个候选人信息，结果已保存到 ./output/zhipin-candidates.json

[JSON 结果...]
```
```

#### 2. 站点经验文件格式

在 `references/site-patterns/zhipin.com.md` 的 frontmatter 添加：

```yaml
---
domain: zhipin.com
aliases: [Boss直聘, BOSS直聘, boss直聘, boss]
outputFile: zhipin-candidates.json
updated: 2026-04-22
---
```

#### 3. 使用流程调整

修改站点经验中"使用流程"的步骤 7：

**修改前**：
```
7. 汇总数据，输出 JSON 结果
```

**修改后**：
```
7. 汇总数据，输出 JSON 结果
   - 检查站点经验 frontmatter 是否定义 `outputFile`
   - 若有，保存到 `./output/{outputFile}`
   - 向用户输出完整 JSON 结果，并告知文件路径
```

### 适用范围

仅适用于定义了 `outputFile` 字段的站点经验文件。通用 CDP 操作不受此规范约束。

### 为什么这样设计

| 设计决策 | 理由 |
|----------|------|
| frontmatter 作为触发器 | YAML 元数据在文档开头，LLM 必然读取 |
| 主文档定义规范 | 适用于所有站点，避免重复说明 |
| 整合到核心步骤 | 保存行为成为输出的一部分，不会被跳过 |
| 固定目录 | 简单可预测，用户易于管理 |
| 覆盖保存 | 每次提取是最新的完整结果，无需历史记录 |

## 改动文件

| 文件 | 操作 | 说明 |

| `SKILL.md` | 新增章节 | 添加"提取结果持久化"章节 |
| `references/site-patterns/zhipin.com.md` | 更新 frontmatter + 步骤 7 | 添加 `outputFile` 字段，调整流程说明 |

## 验收标准

1. 执行候选人提取后，结果自动保存到 `./output/zhipin-candidates.json`
2. LLM 在输出结果时明确告知用户文件路径
3. 目录不存在时自动创建
4. 多次提取时覆盖保存

## 已知限制

1. 仅支持 JSON 格式输出
2. 固定保存到 `./output/` 目录
3. 不支持用户动态指定保存位置

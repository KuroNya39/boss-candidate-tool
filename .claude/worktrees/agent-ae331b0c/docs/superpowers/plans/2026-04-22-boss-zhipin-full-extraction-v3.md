## 详细改动

### 提取脚本变更

**旧版**: 按 `innerText` 分行后逐字段查找

**新版**: 基于 DOM 选择器直接定位，分组输出

### 输出格式变更

**旧版**:
```json
{
  "name": "高健",
  "age": "28岁",
  "school": "中国石油大学（华东）",
  "appliedJob": "ai应用开发工程师"
}
```

**新版**:
```json
{
  "basicInfo": { "name": "于自豪", "age": "24岁", "workYears": "2年", "education": "本科" },
  "workExperience": [{ "time": "2024.03-2026.03", "company": "元展科技", "position": "算法工程师" }],
  "educationExperience": [{ "time": "2020-2024", "school": "郑州工程技术学院", "major": "物联网工程技术", "degree": "本科" }],
  "positionInfo": { "appliedJob": "ai应用开发工程师", "expectCity": "深圳", "expectPosition": "深度学习", "expectSalary": "15-25K" }
}
```

## 风险点

1. **DOM 结构变化**: 如果 Boss 直聘更新页面结构，选择器可能失效。新版设计中字段缺失不报错，可以部分规避此问题。

2. **分隔符变化**: 经历详情使用 `·` 分隔，如果分隔符变化会导致解析错误。但不会影响整体提取流程。

## 执行顺序

1. 读取当前 `zhipin.com.md` 内容
2. 基于设计文档重写站点经验文件
3. 提交改动
